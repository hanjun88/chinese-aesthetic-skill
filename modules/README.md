# 模块实现索引

本目录包含10个可执行实现模块，每个模块对应 guidelines/ 中的一条规则，提供具体的算法、参数和代码实现。

| 模块 | 对应规则 | 优先级 | 核心功能 |
|---|---|---|---|
| spatial.md | 空间秩序 | P0 | 中轴计算、层级检测、布局推荐 |
| void_solid.md | 虚实关系 | P0 | 留白比例计算、不完整入画检测、通透感评估 |
| proportion.md | 比例 | P0 | 经典比例校验、三段式计算、巨构尺度比 |
| material.md | 材料与质感 | P1 | 材质参数推荐、塑料感检测、PBR参数校验 |
| light_shadow.md | 光影布局 | P1 | 光源方案推荐、软阴影参数、体积光配置 |
| color.md | 色彩体系 | P0 | 五方正色校验、配色方案推荐、禁忌色检测 |
| motion.md | 运动动势 | P1 | 东方运动原型、缓动曲线、粒子系统配置 |
| time.md | 时间感 | P1 | 风化参数、昼夜变化、滚动时间递进 |
| taboo.md | 禁忌 | P0 | 禁忌元素检测、四类俗套扫描、AI国风感评分 |
| interaction.md | 交互语义 | P0 | 交互触发链、FSM状态机、移动端适配 |

## 使用方式

每个模块文件包含：
1. **核心算法**：可直接实现的计算逻辑
2. **参数表**：推荐阈值和配置值
3. **代码示例**：Three.js / JavaScript 实现
4. **校验函数**：可被 validate.js 调用的检测逻辑

## 与 guidelines 的关系

- `guidelines/` = 规则定义（为什么、测什么、P0/P1）
- `modules/` = 规则实现（怎么算、用什么参数、代码怎么写）

设计流程：先读 guidelines 理解规则 → 再用 modules 实现 → 最后用 scripts/validate.js 校验。
