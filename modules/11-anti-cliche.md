# 11 Anti-Cliche — 反俗套检测

> 有祥云纹≠中式，有红墙≠中式，有毛笔字≠中式。
> 本模块是整个引擎的**免疫系统**——一旦检测到俗套模式，自动判定设计偏离，必须回炉。

---

## 四类俗套（The Four Clichés）

### 第一类：国潮贴图感（National-Trend Sticker）

**定义**：把"中国元素"当贴纸贴在一个本质上是西方/现代的设计上。

**检测清单（命中任意 2 条即判定）**：
- [ ] 祥云纹样作为背景贴图满铺
- [ ] 回纹/万字纹作为边框装饰
- [ ] 毛笔字/书法字体作为标题（与内容无关，只是"看起来中式"）
- [ ] 红色印章/落款作为装饰元素
- [ ] 青花瓷纹样/敦煌纹样作为图案填充
- [ ] 中国结/灯笼/折扇作为装饰道具
- [ ] 元素之间无结构关系，只是"摆在一起"
- [ ] 去掉这些元素后，设计完全没有东方性

**本质**：东方性只在装饰层，不在结构层。去掉贴纸 = 不是中国设计。

**修复方向**：回到 01-09 模块，从空间秩序、虚实、比例、材料、光影中重建东方性。元素是结果，不是原因。

---

### 第二类：古装影视感（Costume-Drama Look）

**定义**：设计看起来像古装电视剧的布景或海报——高饱和、戏剧化、舞台感。

**检测清单（命中任意 2 条即判定）**：
- [ ] 高饱和正红 + 明黄 + 翠绿的组合（宫墙色）
- [ ] 人物穿着古装但摆拍感强（影楼写真风）
- [ ] 舞台式聚光灯/追光效果
- [ ] 过度的烟雾/干冰效果（舞台雾）
- [ ] 建筑像影视城布景（新、亮、无时间痕迹）
- [ ] 色彩对比极强，无中间调
- [ ] 一切都"太干净""太完美"，无生活痕迹
- [ ] 像电视剧海报/游戏原画

**本质**：把"古代"等同于"戏剧"，缺少真实的时间感和生活感。

**修复方向**：降低饱和度（S ≤ 60%），加入时间痕迹（风化/包浆/使用痕迹），用自然光代替舞台光，加入不完美和生活感。

---

### 第三类：仿古景区感（Antique-Tourist-Spot）

**定义**：设计看起来像仿古商业街/景区入口——粗糙、廉价、拼凑、无章法。

**检测清单（命中任意 2 条即判定）**：
- [ ] 不同朝代的建筑元素混搭（唐屋顶 + 清斗拱 + 明彩画）
- [ ] 斗拱是水泥/塑料做的假斗拱（比例失真）
- [ ] 屋顶用彩色琉璃瓦但建筑等级不够
- [ ] 建筑比例失调（屋顶太小/台基太矮/柱子太细）
- [ ] 彩绘过于鲜艳/满铺（和玺彩画/旋子彩画滥用）
- [ ] 石狮子/赑屃/螭首等瑞兽作为装饰乱放
- [ ] 一切都是"新的仿古"——无真实风化，只有"做旧纹理"
- [ ] 像横店/影视城/仿古一条街

**本质**：对建筑等级和比例无知，把"古代元素"随意拼凑。

**修复方向**：统一朝代/等级（如全部唐代风格），严格遵守三段式比例，斗拱必须有结构逻辑，材料必须真实，时间痕迹必须有物理成因。

---

### 第四类：AI 国风感（AI-Guofeng）

**定义**：AI 生成的"国风"图像的典型通病——华丽但空洞，细节失真，有"塑料感"。

**检测清单（命中任意 2 条即判定）**：
- [ ] 过度光滑的皮肤/材质（塑料感，无纹理）
- [ ] 手指/五官/建筑结构有 AI 典型错误（六指、错位、不合理结构）
- [ ] 服饰/建筑细节是"看起来像"但经不起推敲（纹样无出处、结构不合理）
- [ ] 色彩过于均匀/渐变过于平滑（无真实材质的颗粒感）
- [ ] 一切都"太美了"但没有情绪和故事
- [ ] 人物/建筑漂浮在场景中，无重力感和接触感
- [ ] 光影无来源（均匀照亮，无明确光源方向）
- [ ] 像 Midjourney/Stable Diffusion 的默认国风输出

**本质**：AI 学到了"国风的表面纹理"但没学到结构和逻辑。华丽但空洞。

**修复方向**：加入材质真实感（纹理/颗粒/不完美），确保结构合理（建筑/人体/服饰经得起推敲），光影有来源和方向，加入重力感和接触感，给设计一个具体的情绪和故事。

## 通用俗套检测（Universal Red Flags）

以下问题命中任意一条，设计需要修正：

### 元素层
- [ ] 用了祥云/回纹/万字纹但说不出为什么用
- [ ] 用了毛笔字但内容不需要书法
- [ ] 用了红色但说不出红色的功能（不是"因为中式"）
- [ ] 用了灯笼/中国结/折扇作为装饰
- [ ] 元素数量 > 5 种且无主次

### 色彩层
- [ ] 饱和度 > 60%
- [ ] 用了正红 #FF0000 或明黄 #FFD700
- [ ] 色彩超过 5 种且无比例
- [ ] 阴影是纯黑/纯灰
- [ ] 渐变是彩虹色/多色渐变

### 结构层
- [ ] 去掉所有"中式元素"后，设计和西方设计无区别
- [ ] 无中轴/无层级/无进深
- [ ] 无留白（满铺）
- [ ] 无明确光源（均匀照亮）
- [ ] 无时间感（全新/完美/无痕迹）

### 动效层
- [ ] 用了弹跳/弹性/旋转入场
- [ ] 所有元素同步动画
- [ ] 动画时长 < 1 秒
- [ ] 粒子爆炸/飘散特效
- [ ] 线性运动

## 7位博主验证的禁忌（HIGH CONFIDENCE）

以下禁忌经 Lumax MJ、晓白ALEX、设计师陈欢、异创视界、书香Design、Paul W、RAN design 共7位东方美学创作者的高赞作品交叉验证，无一例外：

| 禁忌 | 验证数 | 说明 |
|---|---|---|
| 高饱和正红 #FF0000 | 7/7 | 全部用暗朱砂 #8B2500 |
| 亮金 #FFD700 满铺 | 7/7 | 全部用哑金/古金，面积≤15% |
| 人物正面特写 | 7/7 | 高赞作品人物全部背影/侧面/剪影/远距离 |
| 满铺祥云纹/回纹 | 7/7 | 传统纹样仅在极小面积出现（服饰细节） |
| 建筑精细斗拱/雕花 | 5/7 | 高赞建筑全部是块面/剪影，细节堆砌=景区效果图 |
| 均匀亮度（无明暗对比） | 5/7 | 高赞作品明暗比≥3:1 |
| 人物占画面>10% | 7/7 | 人物全部≤5%，通常1-3% |
| 元素>3个 | 6/7 | 高赞作品主要元素≤3个 |

**命中任意 2 条 = 设计偏离东方美学，必须回炉。**

## 俗套修复流程

当检测到俗套时，按以下流程修复：

1. **定位**：命中了哪一类俗套？哪几条检测项？
2. **去元素**：先把所有"中式装饰元素"去掉（祥云/毛笔字/红墙/灯笼）。
3. **建结构**：用 01-09 模块重建东方性——中轴、留白、比例、材料、光影。
4. **加真实**：加入材质真实感、时间痕迹、光影来源。
5. **验证**：再次跑检测清单，确认无命中。
6. **归因**：写出"这个设计为什么是中国的"——必须能从结构层面回答。

**关键原则**：修复不是"换一批元素"，是"从结构重建"。如果去掉元素后设计就不是中国的了，说明原来的设计从来就不是中国的。

---

## "为什么是中国的"测试

设计完成后，必须通过以下测试：

### 测试问题
> 如果把这个设计中的所有"中式元素"（红色、飞檐、毛笔字、祥云、灯笼等）全部去掉，剩下的设计还能让人感受到东方性吗？

- **能** → 通过。东方性在结构层。
- **不能** → FAIL。东方性只在装饰层，需要回炉。

### 归因陈述测试
> 用 200 字以内说明：这个设计的东方性建立在哪些结构维度上？

必须能说出 ≥ 3 个结构维度（如：中轴递进的空间秩序、七藏三露的虚实关系、方五斜七的比例克制、天光漏影的光影哲学）。

说不出 → FAIL。

## 与其他模块的关系

- 所有俗套的本质都是"装饰层东方性" → 01 Philosophy（需要结构层东方性）
- 国潮贴图感 → 03 Void/Solid（元素堆砌 = 无留白）
- 古装影视感 → 06 Light（舞台光 = 无天光）+ 07 Color（高饱和）
- 仿古景区感 → 09 Architecture（建筑比例/等级混乱）
- AI 国风感 → 05 Material（塑料感 = 无真实材质）
- 动效俗套 → 08 Motion（弹跳/粒子 = 无气的流动）
