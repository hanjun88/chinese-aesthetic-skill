# 02 Spatial Order — 空间秩序

> 中轴为骨，开间为节，进深为气，尺度为尊。
> 东方空间秩序不是对称癖，是一套**用空间位置表达等级和关系**的语法。

---

## 中轴（Central Axis）

中轴不是"左右对称"，是**权力/意义的中心线**。

- 中轴上的空间等级最高：正殿、主门、核心雕塑。
- 中轴两侧的空间是从属的：配殿、厢房、廊庑。
- 中轴不必是直线——可以转折、可以偏移，但**方向感必须连续**。
- **执行规则**：核心元素必须在中轴上或中轴的终点。核心元素偏置 = 秩序瓦解。

### 中轴的三种用法
| 类型 | 用法 | 案例 |
|---|---|---|
| 严格中轴 | 左右完全对称，表达庄严/权力 | 宫殿、佛寺大殿 |
| 偏移中轴 | 中轴存在但略有偏移，表达自然/文人意趣 | 园林、书院 |
| 隐藏中轴 | 看不见但能感受到的方向线 | 曲折廊道后的豁然开朗 |

## 开间（Bay System）

开间是东方建筑的**基本模数单元**。

- 面阔七间、进深四间——"间"是柱子之间的空间单位。
- 明间（中心开间）最宽，次间次之，梢间最窄——开间宽度本身表达等级。
- 佛光寺东大殿：面阔 7 间（34m），进深 4 间（17.66m），比例接近 √2:1。
- **执行规则**：用开间作为设计模数，所有尺寸是开间的整数或半整数倍。随意尺寸 = 无秩序。

### 开间宽度等级
```
明间(中心) > 次间 > 梢间 > 尽间
  1.2x        1.0x    0.9x    0.8x
```
（x = 标准开间宽度，具体值由建筑等级决定）

## 层级（Hierarchy）

空间层级通过**高度、面积、装饰、位置**四个维度表达。

| 维度 | 高等级 | 低等级 |
|---|---|---|
| 高度 | 高台基、高屋顶、长斗拱出跳 | 低台基、悬山/硬山顶 |
| 面积 | 面阔多间 | 面阔少间 |
| 装饰 | 彩画、琉璃瓦、螭吻 | 素面、布瓦 |
| 位置 | 中轴、上位、坐北朝南 | 两侧、下位 |

- **执行规则**：一个设计中至少有 3 个可辨识的空间层级。所有空间同等级 = 无重点。

---

## 尺度（Scale）

东方尺度不是"人体工程学"，是**人与建筑的关系叙事**。

- 巨构：建筑远大于人，表达敬畏/崇高（宫殿、石窟、摩天楼式的塔）。
- 宜人：建筑与人比例协调，表达亲切/居住（民居、书院）。
- 微型：建筑/物件小于人，表达把玩/冥想（盆景、案头清供、小庭园）。
- **关键技巧**：在一个设计中**并置不同尺度**——巨构中的小人、小庭园中的巨石——制造张力。
- **执行规则**：明确设计的主尺度（巨构/宜人/微型），并至少有一处尺度对比。单一尺度 = 无张力。

### 尺度对比公式
```
主尺度 : 对比尺度 ≥ 5:1 （制造敬畏感）
主尺度 : 对比尺度 ≈ 1:1 （制造亲切感）
主尺度 : 对比尺度 ≤ 1:5 （制造把玩感）
```

---

## 进深（Depth）

进深是东方空间的**时间维度**——空间越深，体验越长。

- 佛光寺东大殿：外槽（回廊）→ 内槽（佛坛），两层进深。
- 大明宫：含元殿 → 宣政殿 → 紫宸殿，三进递进。
- 进深靠：柱列、墙、廊、光影、地面变化来划分。
- **执行规则**：核心空间前至少有 1 层过渡空间。核心空间直接临街 = 无进深。

---

## 空间秩序决策清单

1. **中轴在哪里？** 是严格的、偏移的还是隐藏的？
2. **开间模数是多少？** 所有尺寸是否是开间的倍数？
3. **有几个层级？** 用哪几个维度区分层级？
4. **主尺度是什么？** 有没有尺度对比？
5. **进深几层？** 核心空间被几层过渡包裹？
