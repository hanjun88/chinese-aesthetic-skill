# 04 Proportion — 比例与克制

> 方五斜七，一分长则太长，一分短则太短。
> 东方比例不是数学游戏，是**用数的关系表达宇宙秩序和人的分寸感**。

---

## 方五斜七 — 中国版黄金比

古代中国工匠用"方五斜七"描述 √2 比例。

- 正方形边长为 5，对角线（外接圆直径）约为 7
- 7 ÷ 5 = 1.4 ≈ √2 (1.414)
- 佛光寺东大殿全建筑体现此比例：
  - 面阔 34m : 进深 17.66m ≈ 1.92:1（两个 √2 矩形并排）
  - 正面中轴对分，左右各为一个方圆图（正方形+内接圆）
  - 当心间宽度与建筑总高之间也浮现两个方圆图

### 方五斜七的应用
| 场景 | 比例 | 说明 |
|---|---|---|
| 单开间比例 | 宽:高 = 5:7 或 1:√2 | 竖向空间感 |
| 建筑总平面 | 面阔:进深 = 2√2:1（两个方圆图） | 佛光寺东大殿 |
| 画幅比例 | 3:4 / 2:3（接近 √2 系列） | 避免 16:9 的西方宽屏感 |
| 留白比例 | 实:虚 = 5:7（虚略大于实） | 呼吸感 |

- **执行规则**：核心尺寸关系优先使用 √2 系列（1, √2, 2, 2√2...），而非 φ (1.618) 或随意比例。

## 克制（Restraint）

少即是多，但**少不是空洞**。

### 克制的三个层次
1. **数量克制**：元素数量少到极致。一个空间里视觉焦点 ≤ 1 个。
2. **变化克制**：颜色 ≤ 3 种主色，材质 ≤ 3 种，字体 ≤ 2 种。
3. **装饰克制**：装饰只出现在结构节点上（斗拱、柱头、屋脊），不做满铺装饰。

### 克制 ≠ 简陋
| | 克制 | 简陋 |
|---|---|---|
| 少的原因 | 经过选择，每样东西都有理由 | 没东西可放 |
| 空白 | 有形状、有功能、有呼吸 | 就是空的 |
| 材质 | 少但精，有真实感和时间感 | 少但糙，无质感 |
| 结果 | 高级、宁静、有余韵 | 贫瘠、无聊、无内容 |

- **执行规则**：每删除一个元素，必须确认剩余元素的"存在感"是否增强。删除后更弱 = 删多了。

## 模数系统（Modularity）

东方建筑用**材分制**（宋代《营造法式》）作为模数。

- "材"是标准断面，所有构件尺寸是"材"的倍数
- 一等材到八等材，按建筑等级选用
- 佛光寺东大殿（唐代）斗拱：柱头铺作七铺作双杪双下昂，补间铺作五铺作双杪
- **现代转译**：建立设计模数 m，所有尺寸 = n × m（n 为整数或半整数）

### 模数应用建议
```
基础模数 m = 8px 或 1rem
间距系统: m, 2m, 3m, 4m, 6m, 8m（避免 5m/7m 的随意感）
字号系统: 0.75m, m, 1.5m, 2m, 3m, 4m
颜色层级: 基于同一色相的 m, 2m, 3m 明度阶梯
```

## 比例决策清单

1. **核心比例用了什么？** √2 系列？方五斜七？还是随意的？
2. **有没有模数？** 所有尺寸是否是模数的倍数？
3. **克制到不到位？** 视觉焦点几个？颜色几种？材质几种？
4. **是克制还是简陋？** 每个保留的元素有没有不可替代的理由？
5. **留白比例？** 实:虚是多少？空白有没有形状和功能？

---

## 反模式

- ❌ 16:9 宽屏 + 居中元素（西方电影感，不是东方）
- ❌ 元素数量多但每个都小（密集恐惧，无重点）
- ❌ 颜色超过 5 种且无主次（花乱）
- ❌ 装饰满铺（俗气，无结构逻辑）
- ❌ 为了"极简"而空洞（简陋不是克制）
