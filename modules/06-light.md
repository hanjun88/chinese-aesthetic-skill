# 06 Light — 光影哲学

> 光从天上来，从隙中来，从侧来；不从灯里来。
> 东方光影不是"照明设计"，是**用光塑造空间和时间**。

---

## 光的四种来源

### 1. 天光（Skylight / Diffuse Sky）
- 最主要的光源。来自天空的漫射光，柔和、有方向、有时间变化。
- 早晨偏暖、中午偏白、黄昏偏金、阴天偏蓝。
- 天光从上方和侧方进入，不是从正面均匀照亮。
- **执行规则**：主光源必须是天光（模拟），有明确的时间属性（晨/午/昏/夜/阴）。

### 2. 漏光（Leaked Light）
- 光通过缝隙、孔洞、窗格进入空间，形成**有形状的光影**。
- 漏窗的花格在地面投下花纹，隔扇的纸把光柔化，柱列在地上投下条纹。
- 漏光是东方空间的签名——光不是直接进来，是**被建筑过滤后进来**。
- **执行规则**：至少有一处漏光——光通过有形状的开口进入，在表面留下投影。

### 3. 侧光（Side Light / Raking Light）
- 光从侧面低角度照入，强调材质的纹理和空间的纵深。
- 早晨和傍晚的自然光天然是侧光，能把夯土墙的颗粒、木纹的起伏、地面的不平整全部照亮。
- 侧光制造**长投影**，投影本身是空间的装饰。
- **执行规则**：关键材质表面必须用侧光强调纹理，不可用正面平光。

### 4. 漫反射（Bounced Light / Indirect）
- 光在空间内多次反射后形成的柔和环境光。
- 白色墙面反射天光，水面反射天空，土地反射暖光。
- 漫反射决定了阴影里的颜色——不是黑色，是**有颜色的暗部**。
- **执行规则**：阴影区域必须有漫反射带来的颜色（蓝/暖/绿），不可是纯黑/纯灰。

### 月光法（晓白ALEX验证，1万赞爆款标志性手法）
- 夜景唯一光源=月亮，色调冷蓝（#4A5568 ~ #2D3748）
- 月亮是画面最亮点，亮度≥周围环境3倍
- 整体色温≤5000K（冷调），人物/建筑靠月光轮廓
- 月光下的阴影是深蓝色，不是黑色
- **执行规则**：夜景场景优先使用月光法，不可用路灯/霓虹灯/舞台光

### 暗调中一处光（书香Design验证，"要站在光里"）
- 整体画面平均亮度≤30%（暗调）
- 有且仅有一处明亮区域（月/窗/灯/反射/门后光）
- 亮区是视觉焦点和情绪锚点，人物站在光里或走向光
- **执行规则**：暗调场景必须有且仅有一处光，不可多处均匀亮

## 光不是灯效

### 禁止的"灯效思维"
| 灯效思维 | 东方光影思维 |
|---|---|
| 聚光灯打在主体上 | 天光照亮空间，主体自然浮现 |
| 舞台追光 | 侧光/逆光勾勒轮廓 |
| 霓虹/LED灯带 | 灯笼的暖光透过纸漫射 |
| 均匀亮度 | 有明有暗，明暗比 ≥ 4:1 |
| 灯光颜色变化 | 天光的时间变化（晨暖/午白/昏金） |
| 光斑特效 | 漏窗投影（有形状、有来源） |

- **执行规则**：所有光必须有**来源和方向**。找不到来源的光 = 灯效 = 俗。

## 光影的时间性

光在东方空间中是**时间的表达**。

| 时间 | 光的特征 | 空间情绪 |
|---|---|---|
| 黎明 | 低角度暖光，长投影，蓝紫色天空过渡 | 苏醒、期待 |
| 正午 | 高角度白光，短投影，明暗对比强 | 庄严、清醒 |
| 黄昏 | 低角度金光，最长投影，天空橙红 | 温暖、收敛 |
| 夜晚 | 月光（冷蓝）+ 灯笼（暖橙），对比强烈 | 神秘、内省 |
| 阴天 | 均匀漫射，无明显投影，色彩饱和 | 宁静、忧郁 |
| 雨雪 | 光被水汽散射，更柔和，有动态 | 灵动、诗意 |

- **执行规则**：每个空间/场景必须有明确的时间设定。无时间的光 = 无生命的光。

## 光影构图

### 明暗比例
```
最佳明暗比: 明:暗 = 3:7 或 4:6（暗多于明）
禁忌: 明:暗 = 9:1（过曝，无层次）或 5:5（平，无重点）
```

### 投影的使用
- 投影不是光的副产品，是**构图元素**。
- 柱列的条纹投影、窗格的花纹投影、树枝的斑驳投影——都可以成为空间的主要装饰。
- **执行规则**：至少有一处投影被作为构图元素使用（不是意外出现）。

### 逆光与剪影
- 逆光是东方影像的常用手法：主体背对光源，呈现剪影或半剪影。
- 剪影保留轮廓，隐藏细节，制造神秘感和想象空间。
- Lumax MJ 博客人像大量使用逆光/半逆光。
- **执行规则**：至少有一个主体使用逆光或半逆光，不可全部正面受光。

## 光决策清单

1. **主光源是什么？** 天光？漏光？侧光？漫反射？
2. **时间设定是什么？** 晨/午/昏/夜/阴/雨？
3. **明暗比例？** 明:暗是多少？
4. **有没有漏光投影？** 投影的形状是什么？
5. **阴影里有颜色吗？** 还是纯黑/纯灰？
6. **有没有逆光/剪影？** 哪些元素用了？
7. **所有光都有来源吗？** 有没有找不到来源的"灯效"？

## 反模式

- ❌ 聚光灯/舞台光效果
- ❌ 均匀亮度（无明暗对比）
- ❌ 纯黑阴影（无漫反射颜色）
- ❌ 无时间设定的光
- ❌ 霓虹/LED 光带
- ❌ 光斑特效（无来源的光）
