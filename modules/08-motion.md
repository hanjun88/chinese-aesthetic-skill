# 08 Motion — 动势

> 动如行云，缓如流水，聚如炊烟，散如轻风。
> 东方动势不是"动画特效"，是**气的流动**——缓、连、有重量、有方向、有呼吸。

---

## 东方运动的五种原型

### 1. 云（Cloud）
- **特征**：缓慢、连续、有体积感、边缘柔和、不可预测但有方向
- **缓动**：ease-in-out，超长时长（3-8秒），无明显起止
- **应用**：云海流动、雾气漂移、背景氛围
- **参数**：`duration: 4000-8000ms, easing: ease-in-out, loop: true`
- **禁忌**：粒子飘散（云是连续的体积，不是离散的粒子）、快速移动

### 2. 水（Water）
- **特征**：流畅、有重量、随形而变、有波纹和反射
- **缓动**：先缓后急再缓（入水→下沉→浮起），或持续的正弦波动
- **应用**：水面波纹、倒影、液体流动、转场
- **参数**：`duration: 2000-5000ms, easing: cubic-bezier(0.25, 0.1, 0.25, 1), wave-amplitude: subtle`
- **禁忌**：弹跳、水花特效（除非是核心叙事点）

### 3. 烟（Smoke）
- **特征**：上升、聚集、扩散、有密度变化、半透明
- **缓动**：ease-out（上升加速后扩散减速），有湍流
- **应用**：炊烟、香炉、雾气升腾、转场
- **参数**：`duration: 3000-6000ms, easing: ease-out, opacity: 0.3-0.7, turbulence: low`
- **禁忌**：笔直上升（烟一定有漂移和湍流）、完全不透明

### 4. 风（Wind）
- **特征**：无形、通过其他物体表现、有方向、有阵发
- **缓动**：不规则的阵发（不是匀速），有强弱变化
- **应用**：树叶摇动、衣袂飘动、帘幕摆动、草浪
- **参数**：`duration: 1000-3000ms per gust, easing: irregular, delay: random(0-2000ms)`
- **禁忌**：所有物体同步摇动（风是阵发的，不同物体反应不同）

### 5. 光（Light）
- **特征**：渐变、有方向、有时间感、通过阴影和反射表现
- **缓动**：极缓的明暗变化（模拟云遮日、日落），或突然的漏光
- **应用**：天光变化、漏光移动、阴影拉长、昼夜交替
- **参数**：`duration: 5000-15000ms, easing: ease-in-out, opacity/position shift`
- **禁忌**：闪烁、频闪、快速色变

## 缓动曲线（Easing）

### 东方缓动 vs 西方 UI 缓动
| | 东方缓动 | 西方 UI 缓动 |
|---|---|---|
| 特征 | 极缓、有呼吸、无弹性 | 快入慢出、有弹性、有反馈 |
| 时长 | 2-8秒 | 200-500ms |
| 曲线 | ease-in-out / 自定义长曲线 | ease-out / spring / back |
| 感觉 | 自然、大气、从容 | 敏捷、反馈、效率 |

### 推荐缓动曲线
```css
/* 云缓动 — 极缓，无明显起止 */
--ease-cloud: cubic-bezier(0.25, 0.1, 0.25, 1);

/* 水缓动 — 有重量感 */
--ease-water: cubic-bezier(0.33, 1, 0.68, 1);

/* 烟缓动 — 上升后扩散 */
--ease-smoke: cubic-bezier(0.17, 0.67, 0.12, 0.99);

/* 风缓动 — 阵发 */
--ease-wind: cubic-bezier(0.4, 0, 0.2, 1);

/* 呼吸缓动 — 极慢的正弦 */
--ease-breath: cubic-bezier(0.45, 0.05, 0.55, 0.95);
```

## 动势的禁忌

### HARD FAIL
1. **弹跳入场**（bounce/back easing）——UI 感，不是东方感
2. **旋转入场**（spin/rotate）——花哨，无意义
3. **缩放弹出**（scale 0→1 with overshoot）——廉价感
4. **粒子爆炸**——特效感，不是气的流动
5. **所有元素同步动画**——机械感，无自然
6. **线性运动**（linear easing）——机械，无生命

### SOFT FAIL
1. 动画时长 < 1秒（太急促）
2. 同时超过 3 个元素在动（太乱）
3. 动画无明确的自然原型（不知道在模拟什么）
4. 循环动画有明显的跳切（不连续）

## 动势与空间

### 滚动即进深
- 页面滚动 = 空间进深。每滚一屏 = 进一层。
- 滚动时的视差速度模拟空间深度：远的慢，近的快。
- **执行规则**：滚动驱动的动画必须有视差层次（≥3层：远/中/近）。

### 进入即推门
- 元素入场 = 推门进入。不是从下方滑入，是**从遮挡中浮现**。
- 遮挡物可以是：门、帘、墙、雾、光、画面边缘。
- **执行规则**：元素入场必须有"被遮挡→浮现"的过程，不可直接淡入。

### 静止即呼吸
- 即使是"静态"画面，也应有极缓的呼吸感：云在动、光在移、水在波。
- 呼吸动画极缓（5-15秒循环），几乎不可察觉，但能让画面"活"。
- **执行规则**：每个场景至少有一个极缓的循环动画（云/光/水），即使是背景。

## 动势决策清单

1. **动画的自然原型是什么？** 云/水/烟/风/光？
2. **缓动曲线对了吗？** 有没有用弹跳/弹性/线性？
3. **时长够吗？** ≥ 2秒？有没有呼吸感？
4. **有视差层次吗？** 远/中/近的速度差异？
5. **入场是"浮现"还是"弹出"？**
6. **有静止中的呼吸吗？** 极缓的背景循环？
7. **有没有 HARD FAIL？** 弹跳？旋转？粒子爆炸？
