# 01 Philosophy — 哲学根基

> 设计是"界"的建立。从无界到有界，从外界到内界，从可见之界到不可见之界。
> 东方美学的哲学不是装饰风格，是一套关于**存在与空间关系**的决策系统。

---

## 核心概念

### 界（Boundary）
东方空间的第一动作不是建造，是**划界**。
- 一堵墙、一道门、一架屏风、一层台阶、一片水面——都是界。
- 界不是阻挡，是**转换**：跨过界，状态改变（从外到内、从动到静、从俗到圣）。
- **执行规则**：每个空间必须至少有一个明确的"界"的动作。没有界的空间是无家可归的空间。

### 庇护（Shelter）
建筑的本质是庇护，但东方的庇护不是封闭，是**有选择的遮蔽**。
- 大屋顶庇护的是下方的人和空间，不是把人关起来。
- 庇护感来自上方（屋顶）和侧方（墙/柱），但必须留出朝向（开口）。
- **执行规则**：庇护面 ≥ 3 个方向，开口面 ≤ 1 个方向。全封闭 = 坟墓，全开放 = 无家。

### 进入（Entry）
东方空间中，"进入"是一个**过程**，不是一个瞬间。
- 门不是入口，门是进入的**终点标记**。真正的进入从门前的台阶、廊道、照壁开始。
- 进入序列：远观 → 趋近 → 过门 → 转折 → 豁然（或幽深）。
- **执行规则**：任何重要空间的入口，必须有至少 2 个递进步骤。直接推门而入 = 无仪式感。

### 递进（Progression）
空间不是平铺的，是**层层深入**的。
- 一进、二进、三进——每进一次，空间的私密性和重要性递增。
- 递进靠的是：门、墙、廊、桥、台阶、光影变化，不是靠面积大小。
- **执行规则**：核心空间必须经过至少 2 层递进才能到达。核心空间直接暴露 = 无价值感。

### 朝向（Orientation）
朝向不是风水迷信，是**光、风、景的方向决策**。
- 建筑坐北朝南：冬天纳暖阳，夏天避烈日，迎风而不迎风沙。
- 室内的主要朝向决定了人的行为方向（坐、立、观）。
- **执行规则**：每个空间必须有一个明确的"主朝向"，所有开口和家具朝向它。无主朝向 = 无重心。

## 哲学决策清单

在开始任何设计前，回答：

1. **这个设计的"界"在哪里？** （什么划分了内外/主次/圣俗）
2. **庇护来自哪个方向？** （上方？侧方？什么在庇护什么？）
3. **进入序列是什么？** （观者从哪里开始，经过几步到达核心？）
4. **递进有几层？** （核心空间被几层空间包裹？）
5. **主朝向是什么？** （光从哪来？人面向哪？景在哪边？）

**五个问题答不出三个，设计还没有东方哲学骨架，只有东方装饰皮。**
