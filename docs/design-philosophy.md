# 设计理念与概念说明

## 1. Skill 定位

本 Skill 不是"中式元素收集器"，而是**东方空间美学决策引擎**。它回答的核心问题是：

> **"这个设计为什么是中国的？"**

而不是：

> "这里有没有中国元素？"

去掉所有红色、飞檐、毛笔字、传统纹样后，设计仍然是东方的——靠的是界的建立、虚实的藏露、比例的克制、光的方向、动的节奏。这才是通过。

## 2. 核心哲学

### 2.1 结构先于装饰

东方美学的本质是空间结构，不是表面装饰。中轴、开间、层级、进深、虚实——这些结构决定了设计的东方性，而不是贴上去的纹样和颜色。

**反例**：在一个西方透视构图的页面上贴祥云纹边框+毛笔字标题=国潮贴图感，FAIL。

### 2.2 界的建立

东方空间的核心动作是"界"——门、墙、窗、廊、屏。界划分已知与未知，制造"进入"的仪式感。门后、墙外、窗内是另一个世界。

**ACT0 应用**：云海中的单门就是界的极致——一扇门隔开了此岸与彼岸。

### 2.3 虚实相生

"计白当黑"——空白不是没东西，是画面的一部分。虚（天空/云雾/水面/空地）承载情绪，实（建筑/人物/山）提供锚点。大虚小实 7:3 是东方留白的黄金比例。

### 2.4 比例即秩序

中国古建的比例不是随意的——方五斜七(√2)、三段式、出檐比、巨构尺度比。每一个比例都有来源和功能。比例正确，即使没有任何装饰，设计仍然是东方的。

### 2.5 光有形状

东方光影不是"照亮"，是"漏"——天光从云缝漏下、侧光从屋檐掠过、月光从窗棂洒入。光有形状、有方向、有重量。阴影是深蓝色，不是纯黑。

### 2.6 动势即气

云的卷舒、水的涟漪、烟的升腾、风的掠过、光的游移——五种东方运动原型。动势缓慢（4-8秒周期）、连续（非离散跳变）、有方向（非随机）。

### 2.7 时间即痕迹

时间感不是做旧滤镜，是痕迹——木梁的风化、石面的苔藓、金属的铜锈、光影的昼夜变化。每一处痕迹都在诉说"这里曾经有人/有时间流过"。

## 3. 与四个现有 Skill 的管线关系

```
finesse-brief（需求规格）
  ↓ 输出 Workbench Spec
chinese-aesthetic-skill（本 Skill — 东方美学约束）
  ↓ 输出 色彩/比例/材质/交互/禁忌 约束
finesse-skill（界面设计执行）
  ↓ 输出 UI 设计
frame-smith（动效执行）
  ↓ 输出 视频/动效
finesse-term（术语对齐）
  ↓ 输出 统一术语
```

**本 Skill 的插入点**：finesse-brief 确定"做什么"之后，finesse-skill 开始"怎么做"之前。它不决定功能，只决定美学方向和约束。

## 4. 设计决策流程

```
输入：场景描述 + 现有设计
  ↓
Step 1: 结构归因 — 这个设计的东方性来自哪个结构维度？
  （界/庇护/进入/递进/朝向/虚实/比例/光/动势/时间）
  ↓
Step 2: 维度校验 — 10条规则逐项检查（P0必须通过，P1优化）
  ↓
Step 3: 反俗套扫描 — 四类俗套检测（国潮贴图/古装影视/仿古景区/AI国风）
  ↓
Step 4: 归因陈述 — 用一句话回答"为什么是中国的"
  ↓
输出：评分 + 违规项 + 改进建议 + 归因陈述
```

## 5. 禁忌哲学

禁忌不是"不能用红色"，是"不能在错误的语境用错误的符号"：

- **皇家符号**（五爪龙/琉璃黄瓦/龙凤）仅宫殿场景可用
- **宗教符号**（佛像/卍字/莲花台）仅宗教场景可用
- **传统纹样**（祥云/回纹）仅 ≤5% 面积点缀，不可做背景/边框
- **高饱和色**（正红/亮金/霓虹）仅 ≤5% 点缀，不可做主色

最大的禁忌是**依赖表面元素而非结构**——去掉红色/飞檐/毛笔字后设计不再东方=FAIL。
