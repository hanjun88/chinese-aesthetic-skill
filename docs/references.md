# 参考来源

## 1. 传统建筑与文化

### 1.1 CGTN「大唐营造」交互展
- **URL**: https://news.cgtn.com/event/2025/tang-architecture-h5/index.html
- **内容**: 唐代建筑四大板块——飞檐反宇（佛光寺东大殿）、象天法地（大明宫）、星罗棋布（唐长安城）、术说（大雁塔/紫微宫/莫高窟）
- **蒸馏产物**: tang-architecture Skill（15个能力卡）
- **引用规则**: 比例（方五斜七√2）、建筑（三段式/举折/出檐）、彩画（七朱八白）、规划（三朝制/里坊制/中轴线）

### 1.2 佛光寺东大殿考证
- **来源**: 林徽因、梁思成《记五台山佛光寺的建筑》（1932）
- **关键数据**:
  - 面阔七间（34m），进深四间（17m），高宽比 1:2
  - 斗拱横跨半柱高，出檐深远
  - 内外柱等高，槽式柱网（金箱斗底槽）
  - 举折屋面曲线，凹曲面非直线坡
- **引用规则**: 比例（1:2高宽比）、建筑（斗拱/出檐/柱网）、光影（出檐阴影）

### 1.3 王南《营造天书》/《建筑史诗》
- **作者**: 王南（清华大学建筑学院）
- **核心发现**: 中国古建常用 7:5（≈1.4）比例，与 √2 接近；"方五斜七"的方圆作图法
- **引用规则**: 比例（√2/7:5）、建筑（模数化设计）

### 1.4 《华夏意匠：中国古典建筑设计原理分析》
- **作者**: 李允鉌
- **核心内容**: 中国古典建筑设计原理的系统分析——空间组织、结构体系、装饰逻辑
- **引用规则**: 空间秩序、虚实关系、建筑精神

### 1.5 《营造法式》
- **作者**: 李诫（宋）
- **核心内容**: 宋代建筑官方规范——材分制、斗拱等级、彩画制度、施工定额
- **引用规则**: 比例（材分制）、建筑（斗拱等级）、色彩（彩画制度）、禁忌（斗拱等级匹配）

### 1.6 梁思成全集
- **作者**: 梁思成
- **核心内容**: 中国建筑史研究、《清式营造则例》、古建筑调查
- **引用规则**: 建筑（清式营造则例）、比例（斗拱材分）

### 5.2 HIGH CONFIDENCE 原则（≥3位博主验证）
1. 天空/水面占比 ≥ 60%
2. 全部色彩饱和度 ≤ 50%
3. 人物占画面 ≤ 5%
4. 巨构尺度比 ≥ 5:1
5. 逆光/侧逆光轮廓
6. 建筑用块面剪影非细节
7. 大虚小实 7:3
8. 天际线低于 1/2
9. 不完整入画
10. 禁止高饱和正红明黄
