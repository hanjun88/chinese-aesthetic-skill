# Context: 中式巨构场景资产验收

## 背景

chinese-aesthetic-skill 的核心产出之一是中式巨构场景资产。历史上出现过"仅有装饰性纹理而无结构"、"UI 卡片化布局"、"赛博朋克默认视觉"、"高饱和荧光色泛滥"、"缺乏空间尺度的平面背景"等问题。本 Playbook 建立标准化的资产验收流程，确保中式巨构的视觉和技术质量。

## 中式巨构核心特征

| 维度 | 要求 | 反模式 |
|---|---|---|
| 主体尺度 | 宏大、有压迫感、人在其中显得渺小 | 小场景、装饰物、缺乏尺度参照 |
| 建筑结构 | 真实的梁柱、斗拱、门体、屋檐结构 | 仅有装饰性纹理、无结构逻辑 |
| 材质 | 木材、石材、金属、玉等中式材质 | 塑料感、玻璃幕墙、未来材质 |
| 光影 | 方向性光源、层次分明、氛围浓厚 | 平光、无阴影、高曝光 |
| 空间纵深 | 多层空间、远近层次、透视正确 | 平面背景、无纵深、无透视 |
| 视觉焦点 | 明确的主体和视线引导 | 焦点模糊、元素堆砌 |
| 色彩 | HeartMirror 色彩系统、低饱和温润 | 高饱和荧光、赛博朋克霓虹 |

## 技术验收维度

| 维度 | 检查内容 |
|---|---|
| 分辨率 | 符合规格（如 3840x2160 或目标分辨率） |
| 格式 | WebP/PNG，色彩空间正确 |
| 命名 | 符合命名契约（scene.webp, depth.webp 等） |
| 深度图 | 16-bit，与场景几何一致 |
| 水面遮罩 | 8-bit，水面区域准确 |
| 法线贴图 | 如有，与材质一致 |
| 透明通道 | 如有，边缘干净无白边 |
| scene.json 对应 | 资产清单与 scene.json 声明一致 |

## 视差层级要求

- 场景必须有明确的前景、中景、远景分层
- 深度图必须反映真实的空间关系
- 视差移动时各层移动速度符合深度
- 不得用 CSS scale 替代真实视差

## 约束

- 不得用装饰性纹理替代建筑结构
- 不得出现 UI 卡片化布局
- 不得使用赛博朋克默认视觉
- 不得高饱和荧光色泛滥
- 不得缺乏空间尺度的平面背景
- 资产验收必须基于真实文件检查，不得信任生成工具的自我声明

## 前置条件

1. 资产文件已生成并落盘
2. 设计约束已提取（CA-PB-001 PASS）
3. 技术规格（分辨率、格式、命名）已明确
4. scene.json 或等效配置已生成
