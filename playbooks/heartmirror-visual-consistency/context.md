# Context: HeartMirror 视觉一致性审查

## 背景

HeartMirror 作为统一产品，必须在不同场景、资产和运行阶段保持一致的视觉语言。历史上出现过"场景间风格跳变"、"光照逻辑不统一"、"转场与静态资产不协调"等问题。本 Playbook 建立标准化的视觉一致性审查流程，确保产品视觉语言的统一性和连贯性。

## HeartMirror 设计语言枚举

### 场景类型（Scene Types）

| 场景类型 | 描述 | 典型光照 | 典型视角 |
|---|---|---|---|
| 入境仪式 | 首次进入产品的引导场景，从入口到主空间的过渡 | 晨曦天光，低角度暖光 | 平视→缓慢仰视 |
| 多宇宙观入口 | 不同宇宙/维度的选择入口 | 天光漫射，冷调 | 对称平视 |
| 主空间 | 核心交互场景，中式巨构建筑 | 侧光，明确阴影 | 仰视为主 |
| 过渡空间 | 场景间的转场/走廊/庭院 | 漫射光，柔和阴影 | 平视 |
| 纪念空间 | 叙事性/仪式性空间 | 聚光/顶光，高对比 | 中心对称 |

### 情感基调（Emotional Palette）

| 情感 | 色彩倾向 | 光照特征 | 适用场景 |
|---|---|---|---|
| 温润 | 青蓝+藤黄，低饱和 | 柔和漫射，无硬阴影 | 入境仪式、主空间 |
| 辽阔 | 青蓝+白，高明度 | 天光顶漫射，长阴影 | 多宇宙入口、过渡空间 |
| 敬畏 | 紫+金，中高对比 | 侧光+聚光，深阴影 | 纪念空间、主空间 |
| 宁静 | 青蓝+白，低对比 | 均匀漫射，无明确光源 | 过渡空间 |
| 庄严 | 朱砂+金，高饱和点缀 | 顶光聚射，硬阴影 | 纪念空间 |

### 光照模式（Lighting Models）

| 模式 | 光源方向 | 色温范围 | 阴影风格 | 适用场景类型 |
|---|---|---|---|---|
| 晨曦天光 | 左上方 30°-45° | 3500K-4500K 暖白 | 软阴影，长投影 | 入境仪式 |
| 正午天光 | 顶部漫射 | 5500K-6500K 冷白 | 极软阴影，近乎无投影 | 多宇宙入口 |
| 黄昏侧光 | 侧方低角度 10°-20° | 2500K-3500K 暖橙 | 长硬阴影，高对比 | 主空间、纪念空间 |
| 顶光聚射 | 顶部 90° 聚焦 | 4000K-5000K 中性 | 硬阴影，边缘锐利 | 纪念空间 |
| 环境漫射 | 无明确方向 | 4500K-5500K 中性 | 无阴影，均匀 | 过渡空间 |

### 色彩六角色（Color Roles）

HeartMirror 六色体系，每个颜色在所有场景中承担固定角色，不得跨场景变更：

| 角色 | 颜色 | 参考色值 | 用途 |
|---|---|---|---|
| 境 | 青蓝 | #4A6B7C / #5B8A9E | 主背景、空间基调、大面积底色 |
| 玄 | 紫 | #3D2E4D / #5A4570 | 深邃空间、阴影过渡、神秘感 |
| 脉 | 金 | #C9A96E / #D4B87A | 结构线条、装饰点缀、重要元素描边 |
| 息 | 白 | #E8E4DC / #F0EDE6 | 高光、天光、雾气、文字背景 |
| 印 | 朱砂 | #8B3A3A / #A04545 | 强调点、仪式标记、关键交互元素 |
| 生 | 藤黄 | #C4A35A / #D4B56A | 生命力点缀、自然元素、暖调过渡 |

**一致性要求**：同一角色在不同场景中的色值偏差不得超过 ΔE 5（CIEDE2000），角色分配不得变更（如"境"不得在某个场景中变成主色）。

### 美学特质（Aesthetic Traits）

HeartMirror 的核心美学特质组合，所有场景必须同时体现：

1. **宋式温润**：低饱和、柔和过渡、无锐利边缘、含蓄内敛
2. **晨曦天光**：自然光源感、明亮但不刺眼、暖冷平衡
3. **辽阔敬畏**：大尺度空间、深远透视、人在其中显得渺小
4. **中式巨构**：真实梁柱斗拱结构、宏大建筑比例、非装饰性纹理

**一致性要求**：相邻场景之间的美学特质组合不得突变（如从"宋式温润+晨曦天光"跳到"赛博朋克+霓虹"）。

## HeartMirror 视觉语言要素

| 要素 | 一致性要求 |
|---|---|
| 色彩系统 | HeartMirror 六色体系（青蓝/紫/金/白/朱砂/藤黄）在所有场景中角色一致 |
| 材质语言 | 中式材质（木/石/金/玉）的质感和处理方式统一 |
| 光照逻辑 | 光源方向、色温、阴影风格在同一场景类型内一致 |
| 构图比例 | 视角、空间尺度、视觉焦点位置符合产品规范 |
| 美学特质 | 宋式温润、晨曦天光、辽阔敬畏、中式巨构的组合一致 |
| 叙事节奏 | 首次入境仪式、多宇宙观入口的叙事连贯 |

## CONSISTENCY_REVIEW_FILE Schema

本 Playbook 的核心审查记录文件。由人或 AI 视觉模型在跨场景对比检查后填写，procedure 验证其结构完整性和维度判定。

```json
{
  "reviewId": "string，审查唯一标识",
  "reviewDate": "string，ISO 8601 日期",
  "reviewer": "string，审查者标识（人或模型名称）",
  "scenes": ["string，场景目录路径数组，至少 2 个"],
  "goldenCase": "string，Golden Case 参考目录路径",
  "dimensions": {
    "colorConsistency": {
      "verdict": "PASS|FAIL",
      "evidence": "string，非空，指向标注图/色值采样/参数记录",
      "comparison": "string，非空，场景对对比详情，如'sceneA 主色 #4A6B7C vs sceneB 主色 #5B8A9E，ΔE=3.2 合规'"
    },
    "materialConsistency": {
      "verdict": "PASS|FAIL",
      "evidence": "string，非空",
      "comparison": "string，非空，同类物体在不同场景中的材质对比"
    },
    "lightingConsistency": {
      "verdict": "PASS|FAIL",
      "evidence": "string，非空",
      "comparison": "string，非空，同类型场景光源方向/色温/阴影对比"
    },
    "compositionConsistency": {
      "verdict": "PASS|FAIL",
      "evidence": "string，非空",
      "comparison": "string，非空，视角/尺度/焦点位置对比"
    },
    "styleContinuity": {
      "verdict": "PASS|FAIL",
      "evidence": "string，非空",
      "comparison": "string，非空，相邻场景风格过渡记录，须列出具体场景对"
    },
    "narrativeCoherence": {
      "verdict": "PASS|FAIL",
      "evidence": "string，非空",
      "comparison": "string，非空，入境仪式/多宇宙入口叙事连贯性记录"
    },
    "motionStaticHarmony": {
      "verdict": "PASS|FAIL",
      "evidence": "string，非空",
      "comparison": "string，非空，动态转场与静态资产视觉协调性记录"
    }
  },
  "issues": [
    {
      "category": "aesthetic|technical|asset|narrative",
      "severity": "blocking|important|suggestion",
      "description": "string，问题描述",
      "evidence": "string，非空，具体证据引用",
      "affectedScenes": ["string，受影响场景路径"],
      "suggestedFix": "string，建议修复方向"
    }
  ]
}
```

**字段约束**：
- `dimensions` 必须包含全部 7 个维度，不得缺失
- 每个维度的 `verdict` 只能是 `PASS` 或 `FAIL`
- 每个维度的 `evidence` 和 `comparison` 必须非空
- `issues` 数组可为空（无问题时），但每条 issue 必须有 category/severity/evidence
- `comparison` 字段禁止只写"已对比"或"一致"，必须包含具体场景对和数值/描述差异

## 问题分类（必须区分）

| 类别 | 含义 | 处理方式 |
|---|---|---|
| 美学不一致 | 色彩、材质、风格偏离 HeartMirror 语言 | 返回设计修改 |
| 技术实现问题 | 渲染、压缩、格式导致的视觉偏差 | 修复技术管线 |
| 资产质量问题 | 单个资产的分辨率、细节、完整性不足 | 重新生成或修复资产 |
| 叙事节奏问题 | 场景间过渡、转场、入境仪式不连贯 | 调整叙事设计 |

## 审查维度

1. **色彩一致性**：主色调、辅色、点缀色在场景间的角色是否一致
2. **材质一致性**：同类物体在不同场景中的材质处理是否统一
3. **光照一致性**：同类型场景的光源方向、色温、阴影是否一致
4. **构图一致性**：视角、尺度、焦点位置是否符合产品规范
5. **风格连续性**：相邻场景之间是否有突兀的风格跳变
6. **叙事连贯性**：首次入境仪式、多宇宙入口的叙事是否连贯
7. **动静协调**：动态转场效果与静态资产视觉是否协调

## 约束

- 不得仅用主观评价（"感觉不对"）替代证据记录
- 必须区分问题类别（美学/技术/资产/叙事）
- 必须提供具体的对比证据（截图、色值、参数）
- Golden Case 作为参考基准，不得随意更改
- 审查结论必须可追溯到具体资产和具体问题
- CONSISTENCY_REVIEW_FILE 的 comparison 字段必须包含具体场景对对比，不得空泛

## 前置条件

1. 待审查的场景/资产已生成
2. HeartMirror 设计语言文档可查阅
3. Golden Case 参考已建立并通过验收
4. 设计约束文档（CA-PB-001 输出）已存在
5. 至少 2 个场景用于跨场景对比
