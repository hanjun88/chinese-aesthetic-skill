## 三、新增设计原则

### 原则1：巨构微人仙境配方（Monumental-Micro-Figure-Immortal-Realm）

**定义**：巨大建筑 + 云海/水面 + 白衣微人 = 东方仙境标准配方。三者同时出现时，场景自动获得"仙境感"。

**可执行操作**：
1. 建筑尺度必须是"巨构"——人在建筑面前占比 < 5%
2. 环境必须有云海/雾气/水面——营造"天上"或"仙境"氛围
3. 必须有白衣微人——作为尺度锚点和情感载体
4. 三者缺一不可：只有巨构=建筑效果图，只有云海=风景照，只有微人=人像

**硬参数**：
- 人/建筑高度比 < 1:20
- 云海/雾气覆盖画面 ≥ 30%
- 白衣人必须可见（不能完全融入背景）

**与已有原则关系**：
- 扩展 `micro-figure-anchor`（S3）——从"微人锚定尺度"升级为"巨构+云海+微人"三位一体仙境配方
- 与 `cloud-sea-stratification`（S7）配合（云海的具体形态）
- 与 `monumental-scale` 配合（巨构的具体实现）

### 原则2：神性生物天空点缀（Divine-Creature-Sky-Accent）

**定义**：在天空中放置龙/凤/朱雀等神性生物，作为超现实感的"点睛之笔"。神性生物不是主体，而是天空中的点缀，增加场景的神话维度。

**可执行操作**：
1. 神性生物放置在天空中上部，占画面 10%-25%
2. 生物必须有"飞行感"——翅膀展开、身体呈流线型
3. 生物颜色与天空形成对比（红色朱雀 vs 粉金天空，白色龙 vs 蓝色云海）
4. 生物不是场景主体——主体仍然是建筑/人物，生物是"天空中的符号"

**硬参数**：
- 神性生物占画面 10%-25%
- 必须有明确的飞行姿态（翅膀/身体动态）
- 颜色与背景形成 ≥ 30% 对比度
- 不能占据画面中心（中心留给建筑/人物）

**与已有原则关系**：
- 新增——是 `cloud-grafting`（云物嫁接）的生物形态变体
- 与 `cool-field-warm-point`（color）配合（冷天空=场，暖朱雀=点）

### 原则3：荷花水面仙境基底（Lotus-Water-Immortal-Base）

**定义**：用荷花/荷叶覆盖水面，作为仙境场景的"基底纹理"。荷花不仅是装饰，更是东方仙境的识别符号——"一池荷花"自动将场景从"普通水景"升级为"仙境"。

**可执行操作**：
1. 水面必须覆盖 ≥ 40% 的荷花/荷叶
2. 荷花颜色：粉色/白色（不能用红色/黄色等非传统色）
3. 荷叶大小错落——大荷叶（直径 > 人高）+ 小荷叶 + 荷花苞
4. 水面必须有倒影——建筑/天空/人物倒映在水中
5. 荷花可以"超尺度"——比正常大3-5倍，增加超现实感

**硬参数**：
- 荷花/荷叶覆盖水面 ≥ 40%
- 荷花颜色：粉色/白色（传统色）
- 必须有水面倒影
- 荷叶大小错落（至少3种尺寸）

**与已有原则关系**：
- 新增——是东方仙境特有的植物基底
- 与 `material` 中的"纸/雾"材料配合（荷花的半透明质感）

### 原则4：三步工作流（Three-Step-AI-Video-Workflow）

**定义**：AI中式仙境视频的标准化生产流程——Skill提示词生成 → 分镜图 → 视频生成。每一步都有明确的输入输出和工具选择。

**可执行操作**：
1. **第一步（提示词生成）**：用"东方美学巨构Skill"，输入大白话关键词（如"仰，天宫，荷叶，朱雀，云海"），自动输出场景图提示词+图生视频动态提示词
2. **第二步（分镜图）**：用AI图像生成工具生成4张分镜，分析每张图"为什么好看"（构图/色彩/光影）
3. **第三步（生视频）**：用Kling 3.0 Turbo（简单动态推荐）或Happy Horse 1.1（复杂动态）生成视频

**工具选择指南**：
| 动态复杂度 | 推荐模型 | 适用场景 |
|---|---|---|
| 简单（镜头微动/云雾流动） | Kling 3.0 Turbo | 静态场景+轻微动态 |
| 中等（人物动作/生物飞行） | Kling 3.0 / Happy Horse 1.0 | 有明确主体动作 |
| 复杂（镜头运动+多主体互动） | Happy Horse 1.1（推荐） | 复杂叙事场景 |

**与已有原则关系**：
- 新增——是方法论层面的工作流，不是视觉原则
- 与 `camera-angle-first-prompt`（方法类术语）配合（提示词工程的具体方法）

## 四、提示词工程方法蒸馏

### 4.1 关键词驱动法

视频中展示的核心方法：用**5个简单关键词**驱动复杂场景生成。

**输入示例**：`仰，天宫，荷叶，朱雀，云海`

**关键词拆解**：
| 关键词 | 作用 | 对应设计原则 |
|---|---|---|
| 仰 | 视角（仰视/低角度） | worms-eye-sublime（S9） |
| 天宫 | 主体（巨构建筑） | monumental-scale / cloud-sea-stratification |
| 荷叶 | 环境元素（水面基底） | lotus-water-immortal-base（新增） |
| 朱雀 | 神性生物（天空点缀） | divine-creature-sky-accent（新增） |
| 云海 | 环境（仙境氛围） | cloud-sea-stratification（S7） |

**方法论**：5个关键词 = 1个视角 + 1个主体 + 2个环境元素 + 1个神性符号。这个配方可以复用于任何东方仙境场景。

### 4.2 Skill自动生成提示词

视频中使用的"东方美学巨构Skill"能自动将关键词转化为：
1. **场景图提示词**（用于AI图像生成）
2. **图生视频动态提示词**（用于AI视频生成）

这意味着：用户不需要自己写复杂提示词，只需要输入关键词，Skill自动完成提示词工程。

| 已有原则 | 本视频验证 | 一致性 |
|---|---|---|
| micro-figure-anchor（S3） | 5/6场景有白衣微人 | ✅ 高度一致 |
| cloud-sea-stratification（S7） | 6/6场景有云海 | ✅ 高度一致 |
| monumental-scale | 6/6场景有巨构建筑 | ✅ 高度一致 |
| worms-eye-sublime（S9） | 4/6场景仰视 | ✅ 一致 |
| cool-field-warm-point（color） | 5/6场景暖色调 | ✅ 一致（暖场暖点变体） |
| gold-jade-material-contrast（M1） | 白玉建筑+金色装饰 | ✅ 一致 |
| telephoto-monumental-compression（S8） | 部分场景有长焦压缩感 | ⚠️ 部分一致（视频场景多用广角） |

**新发现**：本视频场景与 IVAN CHIU 系列的差异——
- IVAN CHIU：长焦压缩 + 广角混用，强调"层叠感"
- 风铃Muse：多用广角/仰视，强调"崇高感"和"沉浸感"
- 两者都有：巨构、云海、微人、暖色调——这些是"中式仙境"的核心共识

4. **三步工作流**（Three-Step-AI-Video-Workflow）——Skill提示词→分镜图→视频生成

### 新增术语（5个）
1. `monumental-micro-figure-immortal` — 巨构微人仙境
2. `divine-creature-sky-accent` — 神性生物天空点缀
3. `lotus-water-immortal-base` — 荷花水面仙境基底
4. `three-step-ai-video-workflow` — 三步AI视频工作流

### 方法论发现
- **5关键词配方**：1视角 + 1主体 + 2环境 + 1神性符号
