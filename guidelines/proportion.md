# 规则3：比例（Proportion）

**规则ID：** proportion
**优先级：** P0
**模块文件：** modules/proportion.md

## 目的

运用中国传统建筑比例营造和谐感。比例不是随意的尺寸，是"数"的秩序——方五斜七(√2)、三段式、檐高柱高比，每一个比例都有来源和功能。

## 可测指标

| 指标 | 阈值 | 测量方法 |
|---|---|---|
| 建筑主体宽高比 | 1:1.414(√2) ~ 1:2 | 建筑总宽 / 总高 |
| 层高/开间比 | 1:1 ~ 1:1.5 | 层高 / 开间宽度 |
| 檐高/柱高比 | 1:2 ~ 1:3 | 出檐深度 / 柱高 |
| 三段式比例 | 台基:屋身:屋顶 = 1:2:1 ~ 1:3:1.5 | 各部分高度占比 |
| 人物/建筑尺度比 | ≤ 1:5（推荐 1:10 ~ 1:20） | 人物高度 / 建筑高度 |
| 比例偏差 | ≤ 10% | 实际比例与经典比例的差值 / 经典比例 |

## 实现建议

1. **方五斜七(√2)比例**：建筑面阔与进深的关系常用 √2 比例。正方形对角线 = 边长 × √2 ≈ 1.414。
2. **三段式竖向构图**：台基（1份）→ 屋身（2-3份）→ 屋顶（1-1.5份），自上而下有明确分段。
3. **佛光寺比例**：东大殿高宽比正好 1:2，面阔七间（34m），进深四间（17m）。
4. **出檐深远**：唐代建筑出檐可达柱高的 1/2 ~ 1/3，形成深远阴影。
5. **巨构尺度**：人物与建筑尺度比 ≥ 5:1，爆款常用 10:1 ~ 20:1。

## P0 判定条件

- 偏离常用比例（√2、1:2、7:5）超过 10%
- 三段式比例严重失衡（如屋顶占比 > 50%）
- 人物/建筑尺度比 < 1:5（人物过大，失去巨构感）

## P1 判定条件

- 比例在阈值边缘（偏差 8-10%）
- 三段式存在但分段不清晰

## 示例参考

- **佛光寺东大殿**：高宽比 1:2，面阔34m/进深17m，出檐深远
- **王南《营造天书》**：中国古建常用 7:5（≈1.4）比例，与 √2 接近
- **唐代建筑**：举折屋面曲线，凹曲面而非直线坡
- **Lumax MJ/设计师陈欢作品**：巨构建筑与小人尺度比 10:1 ~ 20:1

## 与其他规则的关系

- 比例是 01 空间秩序 的量化表达
- 三段式比例影响 09 建筑精神 的屋顶/屋身/台基关系
- 出檐深度直接影响 06 光影 的阴影层次
