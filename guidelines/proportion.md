# 规则3：比例（Proportion）

**规则ID：** proportion
**优先级：** P0
**模块文件：** modules/proportion.md
**蒸馏来源：** 大唐营造·佛光寺东大殿（方五斜七/举折/三段式/出檐采光）、7位博主（巨构尺度）

## 目的

运用中国传统建筑比例营造和谐感。比例不是随意的尺寸，是"数"的秩序——方五斜七(√2)、举折凹曲、三段式、檐高柱高比，每一个比例都有来源和功能。核心方法论来自佛光寺东大殿实测：用一把√2尺子锁死当心间面阔、立面总高、左右对称三者，做到"增一分太长、短一分太短"。

## 可测指标

| 指标 | 阈值 | 测量方法 | 来源 |
|---|---|---|---|
| 方五斜七(√2)比例 | 面阔:进深 = 1:1.414，误差≤10% | 建筑总宽 / 总高 | 佛光寺·方五斜七能力卡 |
| 当心间:总高 = 5:7 | 5/7≈0.714，1/√2≈0.707，误差约1% | 当心间面阔 / 建筑总高 | 佛光寺·方圆图实测 |
| 三段式比例 | 台基:屋身:屋顶 = 1:2:1 ~ 1:3:1.5 | 各部分高度占比 | 《木经》"凡屋有三分" |
| 举折坡度 | 唐代和缓（坡度≤30°），明清陡峻（≥40°） | 屋脊高度 / 进深一半 | 佛光寺·举折能力卡 |
| 檐高/柱高比 | 出檐深度 = 柱高的 1/3 ~ 1/2 | 出檐深度 / 柱高 | 佛光寺·斗拱出跳 |
| 人物/建筑尺度比 | ≤ 1:5（推荐 1:10 ~ 1:20） | 人物高度 / 建筑高度 | 5位博主共识（巨构尺度） |
| 比例偏差 | ≤ 10% | 实际比例与经典比例的差值 / 经典比例 | — |

## 实现建议

### 1. 方五斜七(√2)比例 — 方圆作图法

不背数字，画"方圆图"：先定一个基准正方形（边长=当心间面阔），其对角线就是下一步的长度基准。东大殿用它在两处落定比例：
- 正立面沿中轴左右各套一个方圆图，控制左右对称
- 以当心间面阔为边长，让它和建筑总高满足 5:7 的方圆关系

5/7≈0.714，1/√2≈0.707，误差约1%，落在"方五斜七"经验近似范围内。核心是：先选一个设计锚点（当心间面阔），再用方圆作图把√2关系连锁推到总高、开间对称，让零散尺寸由一条比例规则统一。

### 2. 举折屋面曲线 — 先举后折两步法

举折是生成凹曲屋面的计算方法，分两步：
- **先"举"**：根据屋顶进深和屋架规模，定出屋脊相对于檐口的总高度（最大抬升量）
- **后"折"**：从屋脊向檐口方向，逐架降低桁条标高，使屋面横剖面不是直线，而是从脊到檐逐渐放缓的凹曲线

结构动机：上段陡以利排水，下段缓以收阳光，同时形成"如鸟斯革、如翚斯飞"的向上舒展感。

**断代判据**："缓和者古，陡峻者近"——唐代举折和缓（佛光寺为标本），后世屋面坡度一路攀升，到明清趋于陡峻庄严。拿到一座古建筑屋面剖面，目测坡度和缓还是陡峻，即可粗判早晚。

### 3. 三段式竖向构图 — 《木经》"凡屋有三分"

出自《木经》：梁（屋架）以上是"上分"，地面到梁架之间是"中分"，地面以下露在外面的台基是"下分"。
- **上分（大屋顶）**：负责出檐遮雨、形成轮廓
- **中分（木构架屋身）**：立柱梁枋承担围护与承重
- **下分（高台基）**：最初为御潮、防木构下沉，后来演变成等级象征

三段在哲学上对应天、地、人。给古建立面一个默认读图顺序——先看屋顶多重、再看屋身木构、最后看台基高低。

### 4. 出檐采光矛盾平衡法 — 用形态化解功能冲突

矛盾：屋檐要伸得足够远才能排走雨水保护木构墙面，但出檐越长越把日光遮住，室内越暗。

解法不是二选一，而是改变屋檐三维形态：
- 檐口两端向上翻仰翘起（飞檐/反宇），打开檐口下方进光角度
- 配合举折做法，屋面做成和缓凹曲线
- 雨水仍被挑出的檐口排到墙外，日光从起翘的檐口下方斜射入室

本质：当一个构件的两个功能需求冲突时，不要线性拉长其中一个，而是改变构件的三维形态（曲面、起翘），让投影区同时满足"雨影覆盖墙面"和"日照射入室内"。

### 5. 巨构尺度 — 博主验证的三法

5位博主（Lumax MJ/设计师陈欢/书香Design/Paul W/晓白ALEX）独立验证的巨构放大三法：
- 院落被左右画框裁切拉长（暗示画外延续）
- 屋檐/屋脊顶到画面上部1/3线以上（垂直压迫）
- 人物缩成≤画面高度5%的黑点（尺度归零）

三件事同时发生，观众才感知"巨构"——尺度感是对比出来的。

## P0 判定条件

- 偏离方五斜七(√2)比例超过10%
- 举折屋面做成直线坡（无凹曲线），或唐代风格屋顶坡度>35°
- 三段式比例严重失衡（如屋顶占比 > 50%，或无台基）
- 人物/建筑尺度比 < 1:5（人物过大，失去巨构感）
- 出檐深度 < 柱高1/4（出檐不足，失去唐代深檐广翼特征）

## P1 判定条件

- 比例在阈值边缘（偏差 8-10%）
- 三段式存在但分段不清晰
- 举折凹曲线存在但过于陡峻（偏明清风格而非唐代）
- 巨构尺度只满足三法中的1-2项

## 示例参考

- **佛光寺东大殿**：高宽比 1:2，面阔34m/进深17m，当心间面阔与总高满足5:7方圆关系，举折和缓，出檐深远
- **王南《营造天书》**：中国古建常用 7:5（≈1.4）比例，与 √2 接近
- **《木经》**："凡屋有三分，自梁以上为上分，地以上为中分，阶为下分"
- **Lumax MJ/设计师陈欢作品**：巨构建筑与小人尺度比 10:1 ~ 20:1，人物缩成≤5%黑点剪影

## 与其他规则的关系

- 比例是 01 空间秩序 的量化表达
- 三段式比例影响 09 建筑精神 的屋顶/屋身/台基关系
- 出檐深度直接影响 06 光影 的阴影层次
- 举折凹曲线与 05 材料 的屋面瓦材质感配合
- 巨构尺度与 03 虚实 的留白比例配合（实体≤40%）
