# 规则7：运动动势（Motion）

**规则ID：** motion
**优先级：** P1
**模块文件：** modules/motion.md

## 目的

展示水、云、烟、风、光的东方运动方式。动势不是"动画效果"，是"气"的流动——云的卷舒、水的涟漪、烟的升腾、风的掠过、光的游移，每一种运动都有东方的节奏和韵律。

## 可测指标

| 指标 | 阈值 | 测量方法 |
|---|---|---|
| 运动类型 | 云/水/烟/风/光，非弹跳/旋转特效 | 动效类型检测 |
| 缓动曲线 | ease-in-out / cubic-bezier，非 linear/bounce | 缓动函数检测 |
| 运动速度 | 缓慢（周期 4-8秒） | 动画周期检测 |
| 运动连续性 | 连续流动，非离散跳变 | 帧间位移检测 |
| 主体静止 | 画面主体完全静止，仅背景微动 | 主体运动检测 |
| 粒子曲率 | 平滑曲线，非直线运动 | 粒子轨迹检测 |

## 五种东方运动原型

### 1. 云（Cloud）
- 特征：连续体积流动，缓慢卷舒，有密度变化
- 周期：4-8秒循环
- 缓动：ease-in-out
- 参数：opacity 0.3-0.7，速度 0.1-0.3
- 用法：云海/天空/氛围

### 2. 水（Water）
- 特征：涟漪扩散，波纹连续，反射流动
- 周期：2-4秒（涟漪），6-10秒（水面）
- 缓动：ease-out（涟漪扩散）
- 参数：波纹振幅 0.1-0.3，频率 0.5-1.0
- 用法：水面/倒影/雨

### 3. 烟（Smoke）
- 特征：缓慢升腾，螺旋上升，逐渐消散
- 周期：3-6秒
- 缓动：ease-in（加速上升）
- 参数：上升速度 0.2-0.5，消散 opacity 渐变
- 用法：香炉/晨雾/炊烟

### 4. 风（Wind）
- 特征：掠过式，不可见但有影响（树叶动/衣角飘/云移动）
- 周期：1-3秒（阵风），持续（微风）
- 缓动：ease-in-out（阵风）
- 参数：影响范围 100-300px，强度 0.1-0.3
- 用法：环境氛围/交互反馈

### 5. 光（Light）
- 特征：缓慢游移，体积变化，漏光闪烁
- 周期：5-10秒
- 缓动：ease-in-out
- 参数：亮度变化 ±20%，位置缓慢移动
- 用法：天光/月光/体积光

## 实现建议

1. **主体静止，背景微动**：画面主体完全静止，仅背景有极缓微动（云流/水波纹/光变化），营造"活的静物"感。
2. **缓动自然**：用 ease-in-out / cubic-bezier(0.4, 0, 0.2, 1)，禁止 linear 和 bounce。
3. **运动缓慢**：周期 4-8秒，不是 1-2秒的快速动画。
4. **连续流动**：云/水/烟是连续的体积，不是离散粒子跳变。
5. **运动有方向**：云有风向、水有流向、烟有上升方向，不是随机运动。
6. **交互触发的动效**：鼠标扰动云海（风）、点击生长（植物）、滚动下潜（水/漩涡）。
7. **禁止廉价动效**：一切fade-up-together、linear easing、uniform 0.5s duration、bounce overshoot。

```javascript
// 东方运动缓动曲线
const EASTERN_EASING = {
  cloud: 'cubic-bezier(0.4, 0, 0.2, 1)',  // 云的卷舒
  water: 'cubic-bezier(0.25, 0.46, 0.45, 0.94)',  // 水的涟漪
  smoke: 'cubic-bezier(0.55, 0.06, 0.68, 0.19)',  // 烟的升腾
  wind: 'cubic-bezier(0.4, 0, 0.2, 1)',   // 风的掠过
  light: 'cubic-bezier(0.4, 0, 0.2, 1)'   // 光的游移
};

// 云海流动示例
function animateClouds(delta) {
  clouds.position.x += 0.01 * delta;  // 缓慢流动
  clouds.material.opacity = 0.5 + Math.sin(time * 0.3) * 0.2;  // 密度变化
  // 体积流动，非粒子跳变
}
```

## P1 判定条件

- 动画顿卡或不连贯（帧率 < 30fps）
- 动效与用户行为关联不明显
- 使用 linear easing 或 bounce 效果
- 运动周期 < 2秒（过快）
- 主体也在运动（非静止）

## 示例参考

- **frame-smith 动效哲学**：避免"廉价感"，动效有叙事和节奏
- **Lumax MJ 作品**：云海缓慢流动，建筑和人完全静止
- **晓白ALEX 作品**：月光下的云缓慢移动，人影静止
- **反例**：弹跳粒子特效、快速旋转、一切fade-up-together

## 与其他规则的关系

- 云/水/烟的运动需要 04 材料 的半透明/体积材质
