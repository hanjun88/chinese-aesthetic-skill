# 规则10：交互语义（Interaction Semantics）

**规则ID：** interaction
**优先级：** P0
**模块文件：** modules/interaction.md
**蒸馏来源：** ACT0"云海+单门"场景规范、7位博主（物我同生/诗意文案互文/意境转译）、frame-smith动效哲学

## 目的

保持交互与中式美学语境一致。交互不是"按钮点击反馈"，是"物我同生"的境界——鼠标扰动云海、点击触发生长、滚动下潜进入，每一个交互都有对应的意象和叙事。核心方法论来自ACT0"云海+单门"场景的完整交互编排和博主验证的物我同生哲学：交互不是操作，是观者与空间的对话，每一次触碰都唤醒了沉睡的生命。

## 交互触发链

### 鼠标移动（mouseMove）→ 微风拂过 / 云海扰动
- **效果**：云层粒子在鼠标位置产生轻微扰动，形成波纹/流动；鼠标经过处云雾微微散开
- **参数**：扰动半径 = 100-200px，强度 = 0.1-0.3，持续 = 500-1000ms
- **意象**：风起云涌，观者的存在影响了空间；不是"鼠标悬停反馈"，是"风从手边吹过"
- **缓动**：ease-out，扰动自然消散，不留痕迹
- **移动端**：触摸移动替代鼠标移动

### 点击（click）→ 裂隙发光 + 苔藓/花草生长（物我同生）
- **效果**：点击位置出现微光→地面/门面板出现裂隙→苔藓/花草沿裂隙向上生长→生长完成后微光消散
- **参数**：微光持续 = 300ms，裂隙扩展 = 500ms，生长持续 = 1000-2000ms
- **意象**：物我同生，触碰唤醒了沉睡的生命；不是"按钮按下"，是"指尖触地，万物生长"
- **递进**：微光(0.3s) → 裂隙(0.5s) → 生长(1-2s)，三步递进，非一步到位
- **缓动**：生长用 ease-out，自然减速，像真实植物生长
- **移动端**：触摸替代点击

### 点击门（click on door）→ 镜头穿透 / 界的跨越
- **效果**：镜头向门推进，穿过门扉，进入下一世界（云层效果关闭，场景切换，色温/光影变化）
- **参数**：推进持续 = 1500-2000ms，穿过瞬间有白光/模糊过渡（300ms）
- **意象**：界的跨越，从已知进入未知；门是时间与空间的界碑，穿门=穿越
- **缓动**：ease-in-out，先慢（靠近门）后快（穿过）再慢（进入新世界）
- **前置条件**：需先滚动至"心门打开"状态（见滚动交互）

### 拖拽（drag）→ 门体绕垂直轴旋转 / 门的开合
- **效果**：门体围绕垂直轴真实旋转（Three.js 真3D），拖拽角度 = 旋转角度；拖拽时门缝透出微光
- **参数**：旋转范围 = -45° ~ +45°，拖拽结束后回弹到 0°（spring回弹，500ms）
- **意象**：门的开合，观者主动探索；不是"拖拽元素"，是"亲手推开那扇门"
- **缓动**：拖拽时 linear（跟手，1:1映射），回弹用 spring/elastic（自然回弹）
- **移动端**：长按+滑动替代拖拽

### 滚轮（scroll）→ 镜头下潜 + 云雾金粉螺旋 / 深入
- **效果**：镜头沿中心线逐渐下潜，云雾和金色微粒沿镜头运动方向螺旋向内流动；下潜至极限时"心门打开"（门发出微光，可点击穿透）
- **参数**：下潜速度 = 滚动速度 × 0.5，螺旋半径 = 逐渐缩小（从200px到50px），金粉密度 = 逐渐增加
- **意象**：深入，从表面进入核心；不是"滚动页面"，是"一步步走向那扇门"
- **递进**：浅潜(云雾扰动，0-30%) → 深潜(金粉螺旋，30-80%) → 极限(心门打开，80-100%)
- **缓动**：跟随滚动（惯性滚动），停止后 ease-out 减速
- **移动端**：触摸滑动替代滚轮

## 状态机（FSM）

7个状态，完整状态转换：

```
[*] → idle（静止）
idle → cloud-disturb（扰动云海）: mouseMove
cloud-disturb → idle: 光标离开 / 扰动消散
idle → growth-trigger（生长触发）: click（非门区域）
growth-trigger → idle: 生长完成（2s后自动回归）
idle → door-rotate（门旋转）: drag on door
door-rotate → idle: 拖拽结束（spring回弹）
idle → dive-swirl（下潜旋流）: scroll
dive-swirl → gate-open（心门打开）: 滚动至80%+深度
gate-open → enter-new-world（进入新境界）: click on door（穿透）
enter-new-world → [*]: 场景切换完成
```

**状态转换表**：

| 当前状态 | 事件 | 下一状态 | 效果 |
|---|---|---|---|
| idle | mouseMove | cloud-disturb | 云海扰动 |
| cloud-disturb | mouseLeave | idle | 扰动消散 |
| idle | click(非门) | growth-trigger | 微光→裂隙→生长 |
| growth-trigger | timeout(2s) | idle | 生长完成 |
| idle | drag(门) | door-rotate | 门体旋转 |
| door-rotate | dragEnd | idle | spring回弹 |
| idle | scroll | dive-swirl | 下潜+旋流 |
| dive-swirl | scroll≥80% | gate-open | 心门微光 |
| gate-open | click(门) | enter-new-world | 镜头穿透 |
| enter-new-world | transitionEnd | idle(新场景) | 场景切换 |

## 交互编排时间线（ACT0 完整流程）

```
T=0s      场景加载：云海静止，门悬浮半空，月光洒落
           ↓
T=0-3s    初始微动：云海缓慢流动（4-8s周期），月光游移，门微光闪烁
           ↓（用户首次鼠标移动）
T=3s+     cloud-disturb：鼠标位置云海扰动，波纹扩散，500-1000ms消散
           ↓（用户点击云层）
T=3.3s     growth-trigger：微光(300ms)→裂隙(500ms)→苔藓生长(1000-2000ms)
           ↓（用户拖拽门）
T=5s+      door-rotate：门体跟随拖拽旋转(-45°~+45°)，门缝透微光
           ↓（用户滚动）
T=6s+      dive-swirl：镜头下潜，云雾金粉螺旋，浅潜→深潜→心门打开
           ↓（滚动至80%）
T=8s       gate-open：门发出微光，提示可点击穿透
           ↓（用户点击门）
T=8.5s     enter-new-world：镜头推进(1.5-2s)→白光过渡(300ms)→进入新场景
           ↓
T=10.5s    新场景idle：交互循环重新开始
```

## 视频节奏驱动的交互编排（视频蒸馏实证）

> 以下参数来自 video-distillation case_01 实证（AI灵感主义-中式神话，24.7s，BPM 70.5，平均镜头 3.87s），将视频剪辑节奏迁移到交互 FSM 设计。

### 交互节奏借鉴视频剪辑

- **每个交互状态持续 3–5 秒**：对应视频平均镜头时长 3.87s。状态不是毫秒级反馈，而是"一镜一情绪"的呼吸单元。
- **状态间用硬切式切换**（非渐变叠加）：对应视频 6 次硬切、无淡入淡出——交互状态跳转直接切换视觉权重，不靠叠化软过渡（仅背景云海始终在动，提供连续底噪）。
- **末尾状态可加速收束**：最后两个状态持续时间减半（对应视频 2.9s→1.1s 的末尾加速）。

### 情绪曲线映射交互 FSM

视频 6 段情绪曲线（敬畏→崇敬→连接→旅程→升华→抵达）直接映射为交互状态序列：

| 视频段落 | 情绪 | 映射交互状态 | 视觉对应 |
|---|---|---|---|
| 0–4s | 敬畏 | **idle** | 云海静止，门悬浮，月光洒落 |
| 4–8s | 崇敬 | **cloud-disturb** | 鼠标扰动云海，仰视式展开 |
| 8–12s | 连接 | **growth-trigger** | 点击生长，人与空间对话 |
| 12–17s | 旅程 | **dive-swirl** | 滚动下潜，孤身深入 |
| 17–21s | 升华 | **gate-open** | 心门发光，抬手式精神高潮 |
| 21–24s | 抵达 | **enter-new-world** | 穿门而入，新时空 |

### 高潮点设计

- 在交互流程的 **60% 和 80% 位置**设置亮度/饱和度峰值——对应视频 t=12s（流程 49%，色彩突变 Δ亮度23.2/Δ饱和度27.3）与 t=20s（流程 81%，亮度峰值 Δ亮度30.7）。
- 峰值不是随机闪光，是亮度/饱和度在一个状态切换瞬间跳变（视频 4 个色彩节点：12.25/16.5/20.75/23.75s），用色彩突变标记情绪高潮，而非用音效/震动。

### 收束加速

- 交互流程**最后两个状态持续时间减半**：对应视频末尾两镜头 2.9s→1.1s 的加速收束。
- 体感：前 4 个状态各 ~4s 从容展开，gate-open 与 enter-new-world 各 ~1.5–2s 紧凑收束，制造"走向金门"的紧迫感。

### BPM 同步

- 交互动效节奏与 **70 BPM** 配乐同步：每拍 ≈ **0.86s**（60/70.5）。
- **微动效**（云扰动、门微光）= 1 拍 ≈ 0.86s；
- **主动效**（生长、下潜、穿门）= 2–3 拍 ≈ 1.7–2.6s；
- 与视频"2.7 拍/镜头"的呼吸韵律一致。

## 实现建议

1. **交互效果必须具象化**：不用随机颜色闪烁，用云/光/植物/水等自然元素；每个效果有明确的物理/自然对应。
2. **递进式展开**：每个交互有微→显→变的递进，非一步到位；点击生长必须有微光→裂隙→生长三步。
3. **缓动曲线自然**：用 ease-in-out / cubic-bezier，禁止 linear（除拖拽跟手）和弹跳（bounce）；生长用 ease-out，穿透用 ease-in-out。
4. **响应即时**：交互触发 ≤100ms 内有视觉反馈（即使是微光）；不允许"点击后等500ms才动"。
5. **移动端适配**：触摸滑动替代滚轮，触摸替代鼠标移动，长按替代拖拽；移动端触摸目标≥44px。
6. **交互与场景一致**：云海场景用云/雾/光，竹林场景用叶/影/风，不可混用；意象库见 07 动势 的具体意象库。
7. **诗意文案同步**：文案（≤12字）在动势"转"阶段（云雾流动/光游移）同步出现，不解释画面，只补一刀；文案出现时机与交互状态联动。
8. **性能保障**：粒子数≤5000（移动端≤2000），使用GPU加速的WebGL/Shaders，限制长动画帧；低端设备自动降级（减少粒子/关闭体积光）。
9. **FSM完整性**：所有状态可到达终态，无死锁；状态转换有明确的进入/退出效果；同一时刻只有一个主动状态（除idle背景微动）。
10. **物我同生哲学**：交互不是"用户操作界面"，是"观者与空间对话"；每一次交互都改变了空间（云海扰动了/苔藓生长了/门推开了），空间有记忆，不是每次都重置。

## P0 判定条件

- 交互效果与用户意图完全不符（点击无响应或触发不相关动画）
- 交互逻辑混乱（状态机无法到达终态/死锁）
- 使用随机颜色闪烁/弹跳粒子特效（非自然元素）
- 响应延迟 > 500ms
- 拖拽/滚动无跟手感（linear缓动或延迟）
- 移动端无触摸适配（只能用鼠标）
- 点击生长一步到位（无微光→裂隙→生长递进）

## P1 判定条件

- 交互效果存在但不够具象（抽象几何动画）
- 递进关系不清晰（一步到位无层次）
- 缓动曲线不自然（linear 或过度弹跳）
- 诗意文案与动势不同步（文案出现时机不对）
- 性能帧率 < 30fps（桌面）或 < 24fps（移动）
- 交互后空间无记忆（每次都重置，无物我同生感）

## 示例参考

- **ACT0 云海+单门**：鼠标扰动云海→点击生长苔藓→拖拽门旋转→滚动下潜→心门打开→点击穿透进入新境界，完整7状态FSM
- **frame-smith 动效哲学**：避免"廉价感"，动效有叙事和节奏，缓动自然，禁止一切fade-up-together
- **finesse-skill 交互范例**：效果具象化、递进式展开、缓动自然，交互有语义
- **晓白ALEX 诗意文案**：文案≤12字，不描述画面，与云流动同步出现，留空位让观者填
- **反例**：点击→颜色随机闪烁=无具象 FAIL；滚动→页面平移=无下潜意象 FAIL；拖拽→元素乱飞=无门的开合 FAIL
