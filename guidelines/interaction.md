# 规则10：交互语义（Interaction Semantics）

**规则ID：** interaction
**优先级：** P0
**模块文件：** modules/interaction.md

## 目的

保持交互与中式美学语境一致。交互不是"按钮点击反馈"，是"物我同生"的境界——鼠标扰动云海、点击触发生长、滚动下潜进入，每一个交互都有对应的意象和叙事。

## 可测指标

| 指标 | 阈值 | 测量方法 |
|---|---|---|
| 事件-效果匹配度 | 100%匹配 | 每个交互事件有对应的意象效果 |
| 效果具象化 | 非随机颜色/闪烁 | 效果有明确的物理/自然对应 |
| 递进式展开 | 有状态递进 | 交互效果从微→显→变，非一步到位 |
| 响应延迟 | ≤ 100ms | 交互触发到视觉反馈的时间 |
| 动效时长 | 300ms ~ 3000ms | 单个交互动效的持续时间 |
| 缓动曲线 | ease-in-out / cubic-bezier | 非 linear / 非弹跳 |

## 交互触发链

### 鼠标移动（mouseMove）→ 扰动云海
- 效果：云层粒子在鼠标位置产生轻微扰动，形成波纹/流动
- 参数：扰动半径 = 100-200px，强度 = 0.1-0.3，持续 = 500-1000ms
- 意象：风起云涌，观者的存在影响了空间
- 缓动：ease-out，扰动自然消散

### 点击（click）→ 裂隙发光 + 苔藓/花草生长
- 效果：点击位置出现微光→地面/门面板出现裂隙→苔藓/花草沿裂隙向上生长
- 参数：微光持续 = 300ms，裂隙扩展 = 500ms，生长持续 = 1000-2000ms
- 意象：物我同生，触碰唤醒了沉睡的生命
- 递进：微光(0.3s) → 裂隙(0.5s) → 生长(1-2s)，三步递进
- 缓动：生长用 ease-out，自然减速

### 点击门（click on door）→ 镜头穿透
- 效果：镜头向门推进，穿过门扉，进入下一世界（云层效果关闭，场景切换）
- 参数：推进持续 = 1500-2000ms，穿过瞬间有白光/模糊过渡
- 意象：界的跨越，从已知进入未知
- 缓动：ease-in-out，先慢后快再慢

### 拖拽（drag）→ 门体绕垂直轴旋转
- 效果：门体围绕垂直轴真实旋转（Three.js 真3D），拖拽角度 = 旋转角度
- 参数：旋转范围 = -45° ~ +45°，拖拽结束后回弹到 0°
- 意象：门的开合，观者主动探索
- 缓动：拖拽时 linear（跟手），回弹用 spring/elastic

### 滚轮（scroll）→ 镜头下潜 + 云雾金粉螺旋
- 效果：镜头沿中心线逐渐下潜，云雾和金色微粒沿镜头运动方向螺旋向内流动
- 参数：下潜速度 = 滚动速度 × 0.5，螺旋半径 = 逐渐缩小
- 意象：深入，从表面进入核心
- 递进：浅潜(云雾扰动) → 深潜(金粉螺旋) → 极限(心门打开)
- 缓动：跟随滚动，停止后 ease-out 减速

## 状态机（FSM）

```
[*] → 静止
静止 → 扰动云海 : 鼠标移动
扰动云海 → 静止 : 光标离开
静止 → 生长触发 : 点击云层
生长触发 → 静止 : 生长完成
静止 → 门旋转 : 拖拽
门旋转 → 静止 : 拖拽结束
静止 → 下潜旋流 : 滚动
下潜旋流 → 心门打开 : 滚动至深处
心门打开 → 进入新境界 : 点击天门
```

## 实现建议

1. **交互效果必须具象化**：不用随机颜色闪烁，用云/光/植物/水等自然元素。
2. **递进式展开**：每个交互有微→显→变的递进，非一步到位。
3. **缓动曲线自然**：用 ease-in-out / cubic-bezier，禁止 linear 和弹跳（bounce）。
4. **响应即时**：交互触发 ≤100ms 内有视觉反馈（即使是微光）。
5. **移动端适配**：触摸滑动替代滚轮，触摸替代鼠标移动，长按替代拖拽。
6. **交互与场景一致**：云海场景用云/雾/光，竹林场景用叶/影/风，不可混用。

## P0 判定条件

- 交互效果与用户意图完全不符（点击无响应或触发不相关动画）
- 交互逻辑混乱（状态机无法到达终态）
- 使用随机颜色闪烁/弹跳粒子特效（非自然元素）
- 响应延迟 > 500ms

## P1 判定条件

- 交互效果存在但不够具象（抽象几何动画）
- 递进关系不清晰（一步到位无层次）
- 缓动曲线不自然（linear 或过度弹跳）

## 示例参考

- **ACT0 云海+单门**：鼠标扰动云海→点击生长苔藓→拖拽门旋转→滚动下潜→心门打开
- **frame-smith 动效哲学**：避免"廉价感"，动效有叙事和节奏
- **finesse-skill 交互范例**：效果具象化、递进式展开、缓动自然

## 与其他规则的关系

- 交互效果使用 07 动势 的云/水/烟/风/光运动原型
- 交互中的光效遵循 06 光影 的柔光/体积光原则
- 交互中的色彩遵循 06 色彩 的低饱和/五方正色
- 交互状态机与 01 空间秩序 的层级递进对应
