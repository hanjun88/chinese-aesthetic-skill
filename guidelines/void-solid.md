# 规则2：虚实关系（Void / Solid）

**规则ID：** void-solid
**优先级：** P0
**模块文件：** modules/void_solid.md

## 目的

平衡实体与空白。"虚"体现包容、宁静、呼吸；"实"体现稳重、力量、存在。东方美学的核心是"计白当黑"——空白不是没东西，是画面的一部分。

## 可测指标

| 指标 | 阈值 | 测量方法 |
|---|---|---|
| 留白面积比 | ≥ 30%（推荐 50-70%） | 统计画面中天空/云雾/水面/空地的像素占比 |
| 实体占比 | ≤ 70%（推荐 30-50%） | 建筑/人物/山/树等实体像素占比 |
| 通透感 | 至少1处视线穿透 | 门/窗/廊/柱间隙可看到后方空间 |
| 不完整入画 | 至少1个主元素被边缘裁切 | 建筑/山/人物有一侧超出画面边界 |

## 实现建议

1. **大幅开敞空间**：前庭、天井、院落作为"虚"的主体，占画面 50%+。
2. **室内外等高柱网**：佛光寺东大殿内部与外部柱等高，形成空间的连续通透。
3. **雾/云分隔空间**：用半透明云雾层划分前后景，增加纵深的"虚"。
4. **不完整入画**：让建筑的一侧或山体的顶部被画面边缘裁切，暗示更大的存在。
5. **镜面水面**：用水面/地面反射制造上下虚实对称，倒影略暗略模糊。

```javascript
// 虚实比例检测伪代码
function checkVoidSolid(pixelData) {
  const voidPixels = countByCategory(pixelData, ['sky', 'cloud', 'water', 'empty']);
  const solidPixels = countByCategory(pixelData, ['building', 'person', 'mountain', 'tree']);
  const voidRatio = voidPixels / (voidPixels + solidPixels);
  return {
    voidRatio,
    pass: voidRatio >= 0.30,
    recommended: voidRatio >= 0.50 && voidRatio <= 0.70
  };
}
```

## P0 判定条件

- 留白面积 < 场景总面积的 30%
- 建筑/实体占据画面过多，几乎无呼吸空间
- 隐藏或忽略关键空间通透（门后/窗外无内容）

## P1 判定条件

- 留白在 30-50% 之间但分布不均（集中在一侧）
- 有通透但层次不足（仅一层，无纵深）

## 示例参考

- **佛光寺东大殿**：殿前留有开阔院落，内部柱网等高，空间通透
- **宋画山水**：天空/水面常占画面 60-80%，山体仅占 20-40%
- **徽派民居**：白粉墙大面积留白（占70%+），深色屋顶仅占20%
- **Lumax MJ 作品**：天空/云海占 60%+，建筑和人占 ≤30%，人物常被边缘裁切

## 与其他规则的关系

- 虚实比例是 03 比例 的空间表达
- 留白区域需要 06 光影 的天光/漫反射填充
- 不完整入画是 11 反俗套 的核心检测项之一
