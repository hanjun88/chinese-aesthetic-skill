# 规则5：光影布局（Light & Shadow）

**规则ID：** light-shadow
**优先级：** P1
**模块文件：** modules/light_shadow.md

## 目的

营造儒雅静谧的氛围，避免强烈硬光。东方光影不是"照亮"，是"漏"——天光从云缝漏下、侧光从屋檐掠过、月光从窗棂洒入，光有形状、有方向、有重量。

## 可测指标

| 指标 | 阈值 | 测量方法 |
|---|---|---|
| 光源类型 | 天光/侧光/逆光/月光，非点光源 | 光源类型检测 |
| 阴影软硬度 | 软阴影（shadow radius ≥ 2） | Three.js shadow.radius |
| 明暗比 | ≥ 3:1 | 最亮区/最暗区亮度比 |
| 高光覆盖 | ≤ 20% | 高光区域像素占比 |
| 曝光度 | 无过曝（亮度 ≤ 1.0） | 像素亮度检测 |
| 体积光 | 有可见光束（可选） | 体积光效果检测 |
| 光的方向 | 有明确方向（非均匀） | 光源方向检测 |

## 五种东方光

### 1. 天光（Sky Light）
- 来源：天空半球光，柔和均匀
- 色温：5500-6500K（冷白）
- 用法：基础环境光，照亮整体但不产生硬影
- 参数：intensity 0.3-0.5，无方向

### 2. 侧光（Side Light）
- 来源：早晨/黄昏的斜射阳光
- 色温：3000-4500K（暖黄）
- 用法：主光源，从侧面45°照射，产生长阴影和立体感
- 参数：intensity 0.8-1.2，角度 30-60°

### 3. 逆光/侧逆光（Back Light）
- 来源：主体后方的光源
- 色温：4000-5500K
- 用法：轮廓光，主体正面在阴影中，靠轮廓光勾勒边缘
- 参数：主体亮度 ≤ 背景亮度的 50%，轮廓光宽度 ≤ 主体边缘 5%

### 4. 月光（Moon Light）
- 来源：夜晚唯一光源=月亮
- 色温：4000-5000K（冷蓝）
- 用法：夜景主光，月亮是画面最亮点
- 参数：月亮亮度 ≥ 周围环境 3倍，整体色温 ≤ 5000K
- 阴影：深蓝色阴影，非黑色

### 5. 体积光（God Ray / 漏光）
- 来源：光被云层/建筑/窗格遮挡后形成的可见光束
- 色温：与主光源一致
- 用法：氛围光，增加纵深和神圣感
- 参数：透明度 20-40%，数量 ≤ 3条，方向一致

## 实现建议

1. **主光源用侧光/逆光**，不用正面均匀打光。
2. **阴影必须软**：shadow.radius ≥ 2，不用硬边阴影。
3. **明暗比 ≥ 3:1**：有明确的亮区和暗区，不是均匀亮度。
4. **暗调中留一处光**：整体偏暗（平均亮度 ≤ 30%），有且仅有一处明亮区域。
5. **体积光有方向**：光束从云缝/窗格漏下，有明确方向，不是随机光斑。
6. **月光法**：夜景用月光作为唯一光源，冷蓝调，月亮是最亮点。
7. **禁止灯效**：不用点光源照射地面、不用聚光灯、不用霓虹光。

```javascript
// Three.js 光照设置示例
const lighting = {
  // 天光（基础环境光）
  skyLight: new THREE.HemisphereLight(0x87CEEB, 0x362d1f, 0.4),
  // 侧光（主光源，早晨斜射）
  sunLight: new THREE.DirectionalLight(0xFFD700, 1.0),
  // 逆光（轮廓光）
  rimLight: new THREE.DirectionalLight(0x87CEEB, 0.6),
  // 体积光（从云缝漏下）
  godRays: {
    count: 2,
    opacity: 0.3,
    angle: -30,
    color: 0xFFF8DC
  }
};

// 阴影设置
lighting.sunLight.shadow.radius = 4; // 软阴影
lighting.sunLight.shadow.mapSize.set(2048, 2048);
```

## P1 判定条件

- 出现明显硬阴影（shadow.radius < 1）
- 强聚焦光源（点光源照射地面留白）
- 过曝区域 > 10%（亮度 > 1.0）
- 均匀亮度（明暗比 < 2:1）
- 无明确光源方向

## 示例参考

- **晓白ALEX 作品**：暗调月光，月亮是唯一光源，人物靠月光轮廓（1万赞）
