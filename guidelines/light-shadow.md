# 规则5：光影布局（Light & Shadow）

**规则ID：** light-shadow
**优先级：** P1
**模块文件：** modules/light_shadow.md
**蒸馏来源：** 大唐营造·佛光寺（出檐采光平衡/深远檐口软阴影）、7位博主（逆光侧逆光/暗调中一处光/明暗比5:1/暗部有色/体积光）

## 目的

营造儒雅静谧的氛围，避免强烈硬光。东方光影不是"照亮"，是"漏"——天光从云缝漏下、侧光从屋檐掠过、月光从窗棂洒入，光有形状、有方向、有重量。核心方法论来自5位博主独立验证的逆光轮廓法和晓白ALEX的暗调冷暖光9:1：光的高级感不在亮度，在方向、明暗比和暗部的颜色。

## 五种东方光

### 1. 天光（Sky Light）
- 来源：天空半球光，柔和均匀
- 色温：5500-6500K（冷白）
- 用法：基础环境光，照亮整体但不产生硬影
- 参数：intensity 0.3-0.5，无方向

### 2. 侧光（Side Light）
- 来源：早晨/黄昏的斜射阳光
- 色温：3000-4500K（暖黄）
- 用法：主光源，从侧面45°照射，产生长阴影和立体感
- 参数：intensity 0.8-1.2，角度 30-60°

### 3. 逆光/侧逆光（Back Light）— 5位博主共识
- 来源：主体后方的光源
- 色温：4000-5500K
- 用法：轮廓光，主体正面在阴影中，靠轮廓光勾勒边缘
- 参数：主体亮度 ≤ 背景亮度的 50%，轮廓光宽度 ≤ 主体边缘 5%
- 人物多为背影/侧面，不正面露脸（Lumax MJ/晓白ALEX）
- 建筑用块面剪影非细节（逆光时建筑细节消失，只剩轮廓=高级）

### 4. 月光（Moon Light）— 晓白ALEX暗调法
- 来源：夜晚唯一光源=月亮
- 色温：4000-5000K（冷蓝）
- 用法：夜景主光，月亮是画面最亮点
- 参数：月亮亮度 ≥ 周围环境 3倍，整体色温 ≤ 5000K
- 阴影：深蓝色阴影，非黑色
- 暗调冷暖光9:1：大面积冷色（深黑/黛蓝）+ 一点暖光（月白/暖金）破全局
- 底色饱和度 ≤ 30%

### 5. 体积光（God Ray / 漏光）— 书香Design"要站在光里"
- 来源：光被云层/建筑/窗格遮挡后形成的可见光束
- 色温：与主光源一致
- 用法：氛围光，增加纵深和神圣感
- 参数：透明度 20-40%，数量 ≤ 3条，方向一致
- 光从圆窗/云缝/檐下漏下，有明确的入射方向

## 实现建议

### 1. 主光源用侧光/逆光，不用正面均匀打光

5位博主（Lumax MJ/晓白ALEX/设计师陈欢/书香Design/Paul W）独立验证：正面均匀打光=证件照=廉价。侧光/逆光=有方向=有情绪。

### 2. 出檐采光矛盾平衡法（佛光寺，用形态化解功能冲突）

矛盾：屋檐要伸得足够远才能排走雨水保护木构墙面，但出檐越长越把日光遮住，室内越暗。

解法不是二选一，而是改变屋檐三维形态：
- 檐口两端向上翻仰翘起（飞檐/反宇），打开檐口下方进光角度
- 配合举折做法，屋面做成和缓凹曲线
- 雨水仍被挑出的檐口排到墙外，日光从起翘的檐口下方斜射入室

本质：当一个构件的两个功能需求冲突时，不要线性拉长其中一个，而是改变构件的三维形态（曲面、起翘），让投影区同时满足"雨影覆盖墙面"和"日照射入室内"。

### 3. 明暗比 ≥ 5:1

有明确的亮区和暗区，不是均匀亮度。
- 亮区：光源直射处（月光/侧光/体积光）
- 暗区：阴影处，占画面60%+
- 明暗比 5:1 ~ 8:1 为最佳（博主验证）
- 明暗比 < 3:1 = 灰 = 平板 = 廉价

### 4. 暗部有色，不用纯黑

阴影用主色的深色版本，不用纯黑 #000000。
- 朱砂红场景 → 暗部用深赭 #8B0000
- 青绿山水场景 → 暗部用黛蓝 #1A3A5C
- 月白场景 → 暗部用灰蓝 #4A5568
- 暗部有色=空间有深度=高级；暗部纯黑=空间被切断=廉价

### 5. 暗调中留一处光（晓白ALEX）

整体偏暗（平均亮度 ≤ 30%），有且仅有一处明亮区域。
- 那一处光 = 月亮 / 窗棂漏入的月光 / 人物手中的灯 / 远处的暖光
- 冷主:暖点 = 9:1
- 大面积有色黑暗包裹微小暖光 = 孤独感 = 诗意

### 6. 体积光有方向

光束从云缝/窗格/檐下漏下，有明确方向，不是随机光斑。
- 数量 ≤ 3条
- 方向一致（从同一光源方向射出）
- 透明度 20-40%
- 体积光穿过云雾/灰尘时可见，穿过纯净空气时不可见

### 7. 禁止灯效

不用点光源照射地面、不用聚光灯、不用霓虹光。
- 点光源 = 舞台 = 廉价
- 聚光灯 = 审讯 = 廉价
- 霓虹光 = 赛博朋克 = 与东方美学冲突

## P1 判定条件

- 出现明显硬阴影（shadow.radius < 1）
- 强聚焦光源（点光源照射地面留白）
- 过曝区域 > 10%（亮度 > 1.0）
- 均匀亮度（明暗比 < 3:1）
- 无明确光源方向
- 正面均匀打光（主体亮度 ≈ 背景亮度）
- 暗部纯黑（暗部色相差 ≈ 0）
- 逆光场景人物正面露脸（应背影/侧面）

## 示例参考

- **佛光寺东大殿**：出檐深远，形成多层次软阴影，檐下光线柔和，檐口上翘引入侧光
- **晓白ALEX 作品**：暗调月光，月亮是唯一光源，人物靠月光轮廓，冷暖光9:1，底色S≤30%（1万赞）
- **书香Design 作品**：体积光从圆窗漏下，"要站在光里"，明暗比5:1+
- **Lumax MJ 作品**：逆光/侧逆光勾勒建筑和人物轮廓，人物背影/侧面，建筑块面剪影
- **设计师陈欢 红墙古松**：硬光投影在红墙上，松针逆光金边1-2px，明暗对比强烈

## 与其他规则的关系

- 光影决定 02 虚实关系 的视觉层次
- 光的颜色是 06 色彩 的一部分（天光蓝/月光冷/侧光暖）
- 体积光是 07 动势 的静态表达
- 出檐深度（03 比例）直接影响阴影层次
- 逆光轮廓与 04 材料 的材质反光配合（逆光时材质细节消失，只剩轮廓）
- 暗调中一处光与 08 时间感 的夜景时间叙事配合

## IVAN CHIU 云海天宫系列新增原则（11图实证）

> 来源：抖音博主 IVAN CHIU（@_IVANCHIU）Midjourney Prompt Test 系列 11 张图文。全部附带完整提示词。

### 新增原则 L1：体积神光森林（Volumetric-God-Ray-Forest）——柱间雾气中的金色光束森林

- **触发场景**：大殿内部/天门/云瀑/需要"神圣感+空间深度"的场景
- **可执行操作**：
  1. 金色体积光柱从上方/外部斜射穿过雾气和柱间（volumetric god rays slanting through atmospheric mist between columns）；
  2. 光束形成"光的森林"（forming a forest of light），柱与光交替排列；
  3. 尘埃粒子在光束中漂浮（dust particles floating in light beams），增加真实感和体积感；
  4. 光从天门门洞/云瀑/藻井缝隙射出，有明确入射方向。
- **硬参数**：体积光束 ≥ 3条；方向一致（从同一光源方向）；必须有雾气/尘埃介质使光束可见；光束颜色为金色/暖白（4000-5500K）。
- **反例**：光束方向混乱 = 失去"森林"韵律；无介质（纯净空气）= 光束不可见，只剩光斑；光束颜色为冷蓝 = 失去"神光"温暖感。
- **与已有规则关系**：扩展原有"体积光"（第5种东方光）——从"≤3条氛围光"升级为"森林式光束阵列"；与 `caisson-cosmos-ceiling`（S11）配合（大殿内部的光束森林）。

### 新增原则 L2：玉质内发光（Translucent-Jade-Inner-Glow）——半透明白玉建筑的内部光晕

- **触发场景**：玉拱桥/玉柱/玉门/任何白玉材质的超现实建筑
- **可执行操作**：
  1. 建筑材质为半透明白玉（translucent white jade），内部发光（glows from within）；
  2. 使用侧逆光（side backlighting）强化玉质通透感——光从玉质内部透出，边缘形成光晕；
  3. 玉拱桥/玉柱在逆光下呈现半透明光晕，与不透明的金顶/朱红柱形成材质对比；
  4. 发光强度适中（不是霓虹灯），是"温润玉光"而非"刺眼电光"。
- **硬参数**：玉质建筑必须半透明（translucent）；必须有内部发光（glows from within）；必须用侧逆光（side backlighting）；发光颜色为暖白/淡金（3500-4500K）。
- **反例**：白玉不透明 = 失去"玉质通透"核心特征；无内部发光 = 只是白色石头，不是玉；正面打光 = 玉质扁平，失去通透层次。
- **与已有规则关系**：新增——是原有"逆光/侧逆光"（第3种东方光）的材质具体化；与 `gold-jade-material-contrast`（material M1）配合（金的不透明 vs 玉的半透明）。

### 新增原则 L3：金顶受光法（Liquid-Gold-Roof-Sunlit）——鎏金屋顶在阳光下的液态金质感

- **触发场景**：所有带鎏金屋顶的中式建筑（天宫/宫殿/塔/亭）
- **可执行操作**：
  1. 屋顶材质为"液态金"（liquid gold roof tiles），在阳光下呈现金属流动感；
  2. 金顶受光面（sunlit upper section）亮度最高，与冷调云海形成冷暖对比；
  3. 飞檐剪影在螺旋层叠中呈现金色轮廓线（flying eaves silhouettes in spiral）；
  4. 金顶与白玉建筑主体形成"金顶玉身"的经典材质对撞。
- **硬参数**：屋顶必须标注 `liquid gold`；受光面亮度 ≥ 周围环境 2倍；必须与冷调环境（云海/蓝天）形成对比；飞檐必须可见且有金色边缘光。
- **反例**：屋顶为普通黄色 = 失去"液态金"高级质感；金顶与环境同色温 = 失去冷暖对比；无飞檐 = 失去中式建筑识别特征。
- **与已有规则关系**：新增——是原有"侧光"（第2种东方光）的材质具体化；与 `cool-field-warm-point`（color）配合（冷云海=场，暖金顶=点）。
