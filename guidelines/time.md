# 规则8：时间感（Time）

**规则ID：** time
**优先级：** P1
**模块文件：** modules/time.md

## 目的

引入历史厚重感和时间维度。时间感不是"做旧滤镜"，是"痕迹"——木梁的风化、石面的苔藓、金属的铜锈、光影的昼夜变化，每一处痕迹都在诉说"这里曾经有人/有时间流过"。

## 可测指标

| 指标 | 阈值 | 测量方法 |
|---|---|---|
| 材质风化度 | 有磨损/褪色/裂纹痕迹 | 纹理变化检测 |
| 时间变化 | 有昼夜/光影/云流变化 | 动态参数检测 |
| 阴影长度变化 | 随时间变化 | 阴影长度参数 |
| 背景色调变化 | 由朝向暮的渐变 | 色温参数变化 |
| 全程静止 | 禁止完全无变化 | 动态检测 |

## 时间感的三个层次

### 1. 物质时间（风化/包浆/痕迹）
- 木梁：略显风化，纹理加深，颜色变暗
- 石面：有苔藓渐变（底部深绿→顶部浅灰），有裂纹
- 金属：铜锈/氧化，颜色从亮变暗
- 地面：有磨损痕迹（人走多的地方更光滑）
- 墙：有水渍/苔痕/剥落

### 2. 光影时间（昼夜/晨昏/四季）
- 早晨：侧光，暖黄色，长阴影
- 中午：顶光，冷白色，短阴影
- 黄昏：逆光，橙红色，极长阴影
- 夜晚：月光，冷蓝色，深阴影
- 变化：云流、光影移动、色温渐变

### 3. 叙事时间（进入/递进/穿越）
- 滚动=时间推进：从远景→中景→近景→细节
- 点击=时间触发：从静止→生长→绽放
- 门=时间界：穿门=从一个时空进入另一个时空

## 实现建议

1. **材质有时间痕迹**：不是全新的，有风化/包浆/磨损。
2. **光影有时间变化**：云流、光影移动、色温渐变，不是固定不变。
3. **昼夜可选**：可以模拟由朝向暮的渐变（色温从暖→冷→暖）。
4. **滚动=时间推进**：长页面滚动模拟时间/空间的递进。
5. **禁止做旧滤镜**：不用 sepia/grayscale 滤镜假装老旧，用真实的材质纹理和光影变化。
6. **苔藓/植物生长**：点击触发生长，是时间的具象化。

```javascript
// 时间感实现示例
const timeSystem = {
  // 物质时间：材质风化
  materialWeathering: {
    wood: { colorShift: -0.1, roughness: +0.1, wearPattern: 'grain' },
    stone: { mossGradient: true, crackPattern: 'random', wear: 'footpath' },
    metal: { oxidation: true, colorShift: -0.15, patina: 'verdigris' }
  },
  // 光影时间：昼夜变化
  dayNightCycle: {
    morning: { temp: 3500, angle: 15, shadowLength: 3.0 },
    noon: { temp: 5500, angle: 80, shadowLength: 0.5 },
    dusk: { temp: 2800, angle: 170, shadowLength: 5.0 },
    night: { temp: 4500, angle: 120, shadowLength: 2.0, moon: true }
  },
  // 叙事时间：滚动推进
  scrollProgression: {
    0: '远景（云海/天空）',
    0.3: '中景（建筑轮廓）',
    0.6: '近景（建筑+人）',
    0.9: '细节（材质/纹理/苔藓）',
    1.0: '穿越（门后世界）'
  }
};
```

## P1 判定条件

- 场景全程静止无任何时间变化（无云流/光影移动/材质变化）
- 使用做旧滤镜（sepia/grayscale）假装老旧
- 材质过于全新（无风化/磨损/苔藓痕迹）
- 无昼夜/光影变化的可能性

## 示例参考

- **佛光寺东大殿**：木构有千年风化，斗拱裸露，石基有苔藓
- **Lumax MJ 作品**：云海缓慢流动，建筑有风化痕迹，时间感来自云的流动
- **晓白ALEX 作品**：月光下的场景，有时间的静谧感
- **反例**：全新的"古建筑"+ sepia 滤镜=假做旧 FAIL

## 与其他规则的关系

- 时间感是 04 材料 的风化/包浆表达
- 昼夜变化是 05 光影 的动态延伸
- 滚动=时间推进是 10 交互语义 的叙事基础
- 苔藓生长是 10 交互 的点击效果
