# 规则1：空间秩序（Spatial Order）

**规则ID：** spatial-order
**优先级：** P0
**模块文件：** modules/spatial.md

## 目的

建立中式宏伟秩序感。利用轴线、回廊、递进式空间，让观者感受到"进入"的仪式感，而非随机散布的元素堆砌。

## 可测指标

| 指标 | 阈值 | 测量方法 |
|---|---|---|
| 主元素左右对称度 | 误差 ≤ 10% | 计算主元素中心与屏幕中心线的水平偏移 / 屏幕宽度 |
| 场景分层数 | ≥ 2层（前庭/中殿/后堂） | 按深度值分组，统计不同深度层级数量 |
| 主元素位置 | 沿中心轴或黄金分割点 | 主元素X坐标 ∈ [40%, 60%] 或 [30%, 40%]/[60%, 70%] |
| 递进关系 | 前→中→后有明确深度递增 | 相邻层深度差 ≥ 总深度的15% |

## 实现建议

1. **强制中轴对齐**：主门、台阶、柱列与屏幕中心线对齐。Three.js 中用 `Group` 统一平移，所有子元素相对中心定位。
2. **层级递进**：前庭（留白）→ 中殿（主体）→ 后堂（纵深），每层有明确的空间功能。
3. **回廊引导**：用柱廊/墙垣引导视线向中心汇聚，形成"夹景"效果。
4. **偏移规则**：非对称构图时，主体位于黄金分割点（38.2% 或 61.8%），不在正中但保持中轴感。

```javascript
// Three.js 中轴对齐示例
const sceneGroup = new THREE.Group();
const screenCenter = new THREE.Vector3(0, 0, 0);
// 主门定位在中心
mainDoor.position.copy(screenCenter);
// 台阶在门前（Z轴负方向）
steps.position.set(0, 0, -doorDepth * 0.8);
// 柱廊对称分布
leftColumns.position.x = -columnSpacing;
rightColumns.position.x = columnSpacing;
```

## P0 判定条件

- 主元素左右偏移 > 10%（非对称构图且不在黄金分割点）
- 整体缺乏对称结构或层级递进
- 主元素位置随机，无中轴或引导线

## P1 判定条件

- 对称结构存在但层级不清晰
- 递进关系有但深度差不足

## 示例参考

- **佛光寺东大殿**：沿中轴对称布局，面阔七间，进深四间，殿前留有开阔院落
- **紫禁城太和殿**：严格中轴排列，前三殿（太和、中和、保和）形成递进层级
- **唐大明宫含元殿**：高台基+长坡道+左右翔鸾栖凤阁，中轴对称且层级分明

## 与其他规则的关系

- 空间秩序是骨架，决定 02 虚实关系 的分布
- 中轴位置影响 03 比例 的测量基准
- 层级递进为 10 交互语义 的"进入"提供空间基础
