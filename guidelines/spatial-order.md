# 规则1：空间秩序（Spatial Order）

**规则ID：** spatial-order
**优先级：** P0
**模块文件：** modules/spatial.md
**蒸馏来源：** 大唐营造·唐长安城（中轴对称/子城模数/里坊制）、大明宫（三朝制/前朝后寝）、佛光寺（槽式柱网/回字形空间）、7位博主（巨构尺度/三层递进/S形引导线）

## 目的

建立中式宏伟秩序感。利用轴线、回廊、递进式空间，让观者感受到"进入"的仪式感，而非随机散布的元素堆砌。核心方法论来自唐长安城与大明宫的实测：空间秩序不是几何美观，是把"中心=权威""等级=纵深""功能=柱网"这些礼制观念通过空间规划物化。

## 可测指标

| 指标 | 阈值 | 测量方法 | 来源 |
|---|---|---|---|
| 主元素左右对称度 | 误差 ≤ 10%（严格中轴）或 ≤5%（仪式空间） | 主元素中心与屏幕中心线偏移 / 屏幕宽度 | 佛光寺/大明宫 |
| 三级中心递进 | 大中心→中中心→小中心（如都城→宫城→正殿） | 空间层级数 ≥ 3 | 《吕氏春秋》"择中" |
| 场景分层数 | ≥ 2层（前庭/中殿/后堂），宫殿≥3层（外朝/中朝/内朝） | 按深度值分组统计层级 | 大明宫三朝制 |
| 前朝后寝分区 | 南政北居，前朝占40-50%，后寝占50-60% | 南北分区面积比 | 大明宫前朝后寝 |
| 模数控制 | 全城区块面积 = 核心区面积的整数倍或1/2倍 | 子城面积 / 各区块面积 | 唐长安城子城模数 |
| 柱网分槽匹配 | 槽式选择匹配空间功能（回字形=绕行/单槽=并列功能带） | 柱网形式 vs 空间动线 | 佛光寺槽式柱网 |
| 递进关系 | 前→中→后有明确深度递增 | 相邻层深度差 ≥ 总深度的15% | — |
| 巨构尺度锚点 | 人形高度 ≤ 画面高度5%，至少1个点景物 | 人物高度 / 画面高度 | 5位博主共识 |

## 实现建议

### 1. 中轴线对称 — 三级"择中"法

出自《吕氏春秋·慎势》："古之王者，择天下之中而立国，择国之中而立宫，择宫之中而立庙。"

操作分三步：
1. 大尺度选定中心位置立国（外郭正门）
2. 城中选定中心位置立宫（皇城正门→宫城正门）
3. 宫中选定中心位置立庙（正殿）

自南向北拉出一条笔直主轴线，把外郭正门、皇城正门、宫城正殿串成一条直线，以这条轴为镜像轴左右对称。主轴上的建筑等级最高、体量最大；轴两侧附属建筑按对称原则成对布置。

唐长安城此线被定位为历代中轴传统的"最高范本"：自明德门→朱雀门→承天门→太极殿。

### 2. 三朝制 — 等级递减、私密性递增的纵深序列

沿中轴线自南向北布置三级政务空间：
- **外朝**（含元殿）：最高等级、最大排场、使用频率最低。元日朝贺、大朝会、外宾朝贡——一年才几次的国家级大典。殿前有龙尾道、两侧有阙楼。
- **中朝**（宣政殿）：正衙、常朝。每月朔望（初一、十五）在此受朝议政，讨论重大事件。中书、门下等中央官署环布左右。
- **内朝**（紫宸殿）：便殿、日常起居。皇帝日常在此议事生活。官员进入内朝须经宣政殿左右的东西上阁门（"入阁"），有严格品阶班序限制。

本质：把政治等级和准入门槛物化到空间纵深上——越往北面走，等级越高、人越少、越私密。

### 3. 前朝后寝 — 南政北居的总图骨架

把整个宫殿群沿南北中轴线切成南北两半：
- **南面（前朝）**：听政办公区，三大殿沿中轴排列
- **北面（后寝）**：帝后生活区，以太液池为中心布置居住和园林

大明宫实例：南部含元/宣政/紫宸三大殿为前朝；三大殿以北为后寝，中央低洼处凿太液池，池中筑蓬莱/方丈/瀛洲三岛（"一池三山"），把神话宇宙图式转译为后寝园林。

前朝对官员按等级递进开放，后寝仅限皇室与近侍。"国"与"家"在中轴线上前后并置。

### 4. 子城模数法 — 城市即模数

以城市核心区（皇城+宫城整体，称"子城"）为基本模数单元，向外逐级复制和缩放：
1. **先定子城**：量出长宽（唐长安子城东西约2820m、南北约3336m）
2. **东西两侧复制**：子城东西两侧各划12坊，这12坊面积恰好约等于一个子城面积
3. **南部缩放**：皇城南面9排坊，每3排坊面积 = 子城的1/2
4. **定坊长宽比**：皇城区域长宽比约9:6，坊按宽6里、长9里设计

全城任何区块面积都不是随意定的，而是核心区面积的整数倍或1/2倍。几何美感来自模数控制，不是偶然整齐。

### 5. 里坊制 — 围合+门禁+时控+礼制微调

基本单元是被夯土墙围合的矩形坊：
- 坊墙厚2.5-3m，四边开门（标准坊）
- 坊内约15m宽十字街，把坊切成4个居住小区
- 傍晚街鼓一响，所有坊门关闭，入夜后街上禁行（宵禁）

**礼制例外**：正对皇宫的皇城南四列坊取消南北门、只开东西两门，十字街改东西横街——切断从外郭直通宫城的南北视线与动线。坊的开门方向和内部街网形态，取决于这个坊在城市礼制格局中相对于皇宫的位置。

### 6. 槽式柱网 — 分槽=空间功能+动线+观看方式

殿身靠内柱列把殿内空间纵向切成若干"槽"，四种并列选项：
- **金箱斗底槽（回字形）**：内外两周柱列套成"回"字，内槽围合核心圣区（佛坛），外槽留作绕行通道。适用于需要绕佛仪式的佛寺。
- **单槽/双槽**：一列或两列内柱把空间纵向切成一条或两条通带。适用于并列功能带的殿堂。
- **分心槽**：殿正中一列柱把空间对称劈成两半。适用于沿中轴对称、中央贯通的划分。

关键不是"哪种好看"，而是**分槽方式 = 空间功能 + 人的动线 + 观看方式**。柱网选择是结构-空间-仪式一体化决策。

佛光寺东大殿即金箱斗底槽：内外柱两周共36根，内槽=佛坛范围（唐代塑像三十余尊），外槽=人行通道，信众沿外槽顺时针绕行内槽佛坛一周。

### 7. 博主验证的空间构图法

- **三层空间递进+框景**：前景（占下/侧边缘15-25%，荷叶/古松枝/悬崖，作用是"框住"中景）→ 中景（视觉中心，占30-40%）→ 远景（上部/远端，颜色比中景淡一档/灰一档/冷一档）。三层之间必须有过渡物（云雾/水面/S形水流）。
- **S形引导线**：让一条S形曲线（水流/山路/雾带/长廊）从前景一角蜿蜒穿到画面深处，占画面宽度1/3-1/2，主角落在曲线远端三分点。直线是参观路线，S线是游园路线。
- **三远法数字构图**：高远（自山下仰山巅，竖版立轴，情绪=崇高永恒）、深远（自山前窥山后，近山浓墨实远山淡墨虚，情绪=幽深神秘）、平远（自近山望远山，横向展开，水面/云雾占50%，情绪=辽阔冲淡）。

## P0 判定条件

- 主元素左右偏移 > 10%（非对称构图且不在黄金分割点）
- 宫殿/仪式空间缺乏三级中心递进（大→中→小）
- 三朝制空间等级混乱（外朝/中朝/内朝功能不分）
- 前朝后寝分区缺失或南北颠倒
- 柱网分槽与空间功能不匹配（如需要绕行动线却用了分心槽）
- 整体缺乏对称结构或层级递进
- 巨构场景无尺度锚点（无人物/点景物，或人物>画面高度5%）

## P1 判定条件

- 对称结构存在但层级不清晰
- 递进关系有但深度差不足
- 模数控制有但局部区块偏离整数倍关系
- 三层空间递进有但中远景之间缺过渡物
- S形引导线有但主角不在三分点

## 示例参考

- **唐长安城**：子城模数法规划，108坊方格网，中轴自明德门至太极殿，里坊制宵禁管理
- **唐大明宫**：三朝制（含元→宣政→紫宸）+ 前朝后寝（南三大殿北太液池）+ 一池三山
- **佛光寺东大殿**：金箱斗底槽（回字形）36柱，内槽佛坛+外槽顺时针绕佛动线
- **紫禁城太和殿**：严格中轴排列，前三殿形成递进层级
- **Lumax MJ/设计师陈欢作品**：巨构+小人尺度锚点，院落裁切拉长，屋檐顶到上部1/3线

## 图文蒸馏新增原则（63图实证）

> 来源：img_01–img_63 三批蒸馏（云舟超现实9图 + 建筑奇幻12图 + 雪中宫殿9图 + 金缮矿物6图 + 色卡12图 + oneone紫7图）。以下原则均带可执行参数。

### 新增原则 S1：云物嫁接（Cloud-Grafting）——云不是背景，是可被"穿"的器物骨架

- **触发场景**：超现实诗意主视觉 / 品牌KV / 小说封面 / 游戏概念图
- **可执行操作**：
  1. 选定一个中式器物骨架（牡丹 / 伞 / 灯笼 / 塔 / 舟 / 折扇 / 琵琶）；
  2. 用积云/烟雾的体积感去填充骨架轮廓，但必须保留骨架的关键识别特征（花瓣层叠 / 伞骨放射 / 流苏垂坠 / 瓦檐翘角）；
  3. 骨架内部设置**唯一**自发光源（暖金 #E8B870 ~ #F5D090 或冷白），云体变成一盏"灯"；
  4. 用一个微小人（≤画幅3%）通过绳索/长杆/船桨与云物产生物理连接，形成叙事闭环。
- **硬参数**：云物发光面积 ≤ 画面 40%；全图只允许 1 个核心发光体；连接物（杆/绳）宽度 ≤ 画面宽度 1%。
- **反例**：只是"天空中有一朵长得像花的云"（无器物骨架、无人-物连接）= 失败；发光面积 > 40% = 霓虹灯感。
- **与已有规则关系**：补充 `monumental-scale`（巨物尺度的具体化），新增母题。

### 新增原则 S2：地平线建筑（Horizon-Architecture）——把建筑压成一条无限延伸的水平线

- **触发场景**：崇高感/空寂感主视觉、纪录片封面、片头KV、山水意境海报
- **可执行操作**：
  1. 在画面 **1/2 ~ 2/3 高度** 设一道无限延伸的水平面（雪墙 / 云海 / 沙脊 / 高台基）；
  2. 让建筑只露屋顶线 / 飞檐 / 门楣，其余被该水平面"切掉"（至少切掉建筑 70%）；
  3. 门 / 花窗作为**唯一竖向开口**，置于水平面中轴或三分点；
  4. 人物放在水平面下方 5–10% 高度处，背对建筑。
- **硬参数**：水平面必须出画（两端在画面外消失）；建筑被裁切比例 ≥ 70%；画中不得出现树木/道具把建筑重新"物体化"。
- **反例**：整座建筑完整画出 = 回到"物体观看"；水平面在画面内可见尽头 = 变成墙而不是地平线。
- **与已有规则关系**：补充 `incomplete-framing`（不完整入画）的极端形态——从"切一角"升级为"切成地平线"。

### 新增原则 S3：微人锚定（Micro-Figure-Anchor）——人物是标点，不是角色

- **触发场景**：所有需要"尺度感 + 孤独感"的国风超现实视觉
- **可执行操作**：
  1. 人物高度 ≤ 画幅高度 **3%（横版）/ 4%（竖版）**；
  2. 人物统一穿深黑/深灰/深褐长袍，不戴彩色配饰（**禁止红衣**，否则破坏冷场暖点）；
  3. 位置永远在中轴 / 三分点 / 灭点上，从不随机；
  4. 姿态固定为"背对 / 侧对、站立或缓行"，禁止面部特写、禁止多人（人数 = 1）；
  5. 必须在做一件**具体的小事**（举灯 / 推车 / 背篓 / 系绳），动作越小，巨物压迫感越强。
- **硬参数**：人物占画面面积 ≤ 3%；与前景尺度参照形成 5–10 倍尺度差。
- **反例**：人物 > 5% 且正面露脸 = 观众开始"读故事"而不是"感受空间"；两人以上 = 失去孤独感。
- **与已有规则关系**：细化 `monumental-scale`（巨构尺度）的人物姿态/着装/动作约束。

### 新增原则 S4：人纹退化（Human-as-Pattern）——人群从角色降级为装饰纹样

- **触发场景**：宫殿 / 坛城 / 仪式场景、宗教建筑效果图、史诗游戏宣传图
- **可执行操作**：
  1. 在宏大建筑/道路前放置 10~50 人，**严格等距**排列，沿一条线（台阶/道路/桥）；
  2. 背景人群缩小到画面高度的 **1%~3%**，无法辨认面部；
  3. 手持统一道具（灯 / 旗 / 杖），使他们在视觉上合并为一条"发光带"或"装饰边"；
  4. 前景单独放置 1~2 个稍大的人物（**5%~8%**）作为"观看入口"，与背景人纹形成 5~10 倍尺度对照。
- **硬参数**：背景人纹必须等距、同向、无个体动作；前景人 > 背景人 5 倍以上。
- **反例**：人群随机分布或自由活动 = 庙会人群，失去仪式感；前景背景同尺度 = 没有层级。
- **与已有规则关系**：新增——把人物从"尺度锚点"升级为"重复韵律元素"。

### 新增原则 S5：反重力悬构（Anti-Gravity-Suspension）——建筑必须违背至少一条重力常识

- **触发场景**：建筑概念设计、游戏世界观场景、科幻古风融合图、小说封面
- **可执行操作**：
  1. 选定一个中式建筑类型（塔/殿/门/桥/廊/船塔同构）；
  2. 让它违背以下至少一条重力常识：
     - 建筑半悬于垂直悬崖外，底部无支撑；
     - 建筑建在船上 / 云上 / 冰上（支撑物本身不可支撑）；
     - 屋檐/平台悬挑超过主体宽度 **3 倍**；
     - 缆绳/冰柱/瀑布从建筑向下无限延伸，无落地。
  3. 建筑材质必须是"重"的——石、木、青铜、瓦（越重的材料做越轻的事，反差越强）；
  4. 必须配一个真实尺度的微人，站在"安全"位置（栈道/台阶/地面）**脚踏实地**仰望。
- **硬参数**：禁止解释结构合理性（不加柱子/基座）；禁止让人物也悬浮；禁止用透明/发光材质做建筑本体。
- **反例**：玻璃/水晶宫殿 = 失重感消失（材质轻所以飞起来合理）；人物也飘 = 全场景失重，反衬消失。
- **与已有规则关系**：新增——是 `monumental-scale` 与 `incomplete-framing` 之外的第三种崇高制造机制。

### 新增原则 S6：框中洞天（Framed-Portal）——用建筑构件制造"画中画"异质入口

- **触发场景**：意境海报、品牌世界观设定、小说章节页、游戏场景过渡图
- **可执行操作**：
  1. 选一个中式构件作前景画框：门 / 窗 / 廊柱 / 飞檐 / 月洞门 / 石牌坊；
  2. 画框占画面边缘 **15%~25%** 面积；
  3. 框内必须是与外部环境**完全异质**的空间（门外是海/星空/佛国/雾山，不是"另一个房间"）；
  4. 画框材质必须厚重有年代感（木纹/石纹/铜锈），与内景空灵形成材质对比；
  5. 画框与内景之间**不加地面/地板**，让门直接悬浮在虚空中。
- **硬参数**：画框内禁止放人物（人物只能在画框外）；禁止用现代材质（玻璃/金属框）。
- **与已有规则关系**：细化 `boundary-threshold`（界）——从"分隔空间"升级为"框中异质世界"。
