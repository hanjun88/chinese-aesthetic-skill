# 规则6：色彩体系（Color System）

**规则ID：** color
**优先级：** P0
**模块文件：** modules/color.md
**蒸馏来源：** 大唐营造·佛光寺（七朱八白朱材白壁）、7位博主（君臣佐使/红金绿公式/金色节制/国色单色/暗调冷暖光/紫金东方），45个验证色值

## 目的

使用中国传统色彩体系，体现文化内涵。色彩不是装饰，是"五行"的对应——青(木)、赤(火)、黄(土)、白(金)、黑(水)，每一种颜色都有方位、季节和象征意义。核心方法论来自国画千年验证的君臣佐使配色体系和7位博主独立验证的色彩公式：色彩的高级感不在颜色本身，在比例、饱和度错峰和造型分工。

## 核心配色方法论

### 1. 君臣佐使 70:20:10（国画千年验证，4位博主暗合）

Paul W 从国画色彩方法论提炼，异创视界/ran design/Lumax MJ 独立暗合：
- **君（主色）70%**：定调，大面积铺底，决定画面情绪
- **臣（辅色）20%**：稳场，支撑主色，形成对比或和谐
- **佐（点缀色）10%**：提神，小面积高对比，引导视线
- **使（背景/留白）**：实际操作中背景常占30-40%，君臣佐使在剩余60-70%内分配

判别题：把画面颜色按面积排序，最大的是不是在"定调"而不是在"抢眼"？最大的颜色抢眼=君臣颠倒=廉价。

### 2. 红金绿高级感公式（Paul W，饱和度+比例+造型三控）

红配绿最容易俗，但国画里红金绿是经典。四步控制：
1. **饱和度错峰**：红走高饱和 #C62828，绿走中低饱和 #00695C/#2F4F4F（墨绿/石绿压灰），不可两者都高饱和
2. **比例锁死 3:7**：红占3成、绿占7成（或反之），绝不对半
3. **造型错峰**：红做极简大块背景，绿做有皴法/轮廓的山峦造型
4. **黄色绢本底色**：#F5DEB3 中和红绿冲击

### 3. 金色节制 ≤18%（6位博主共识）

金色画面覆盖面积硬上限 18%。
- 大幅金只用于：龙脉主峰轮廓、宫观主体、瀑布/河流自发光带、峰顶尖光
- 金色必须分层：近景金线厚重清晰、远景淡金虚化、阴处碎金隐现
- 金色必须配深色底（群青 #1A3A8C / 深紫 #4A148C / 墨黑 #0A0A0A），靠冷暖明度对比让金"发光"
- 色值：哑金 #B8860B ~ #DAA520，禁止 #FFD700 亮金

### 4. 国色单色背景系统（异创视界，色即人格）

用一种传统色铺满整个画面（60-70%纯背景），人物的瞳孔、唇色、服饰全部与这一色同频：
- 国色·绿 #2E8B57
- 国色·橙 #E67E22
- 国色·柘 #B8860B
- 国色·中国红 #C0392B
- 国色·黛蓝 #2C3E6B

颜色因此获得人格——不是"绿色背景"，是"绿的人格"。诗意文案四字对仗与画面互文。

### 5. 暗调中一处光（晓白ALEX，冷暖光9:1）

暗调孤独叙事的色彩配方：
- 底色：深黑底 #0D0D1A ~ #2C3E50，占60-80%，底色饱和度≤30%
- 主色：月白 #F0E6D3（月光/人物），占15-25%
- 暖光点：暖金 #D4AF37，≤5%
- 冷暖光比 = 9:1（大面积冷色+一点暖光破全局）

核心：把看客的"慌"都吞进画里——用大面积有色黑暗包裹微小暖光，孤独感是尺度×色温×动势的物理乘积。

### 6. 紫金东方（RAN design，情绪>形态）

不画具体山石，用紫金光雾暗示"烟光凝而暮山紫"：
- 深紫 #4A148C（60%）
- 浅紫 #9575CD（25%）
- 金光带 #D4A017（≤15%）
- 一条金色光带引导视线，商业KV因此获得东方精神而非东方符号

红黑变体：纯黑 #0A0A0A（60%）+ 深红弥散 #B71C1C（30%）

### 7. 七朱八白朱色（唐代建筑，朱材白壁）

唐代官式涂装的标准化基调：
- 朱色：近紫的朱红（非鲜艳正红），阑额满刷
- 白色：等长条块均匀分布于朱底，白条端头入柱
- 彩画=结构可读性工具，不是装饰

## P0 判定条件

- 主色偏离五方正色范围（ΔE > 30）
- 出现霓虹色/荧光色/紫外光色（如 #00FF00、#FF00FF）
- 使用 #FF0000 正红或 #FFD700 亮金作为主色
- 色彩饱和度 > 60% 且面积 > 20%
- 金色覆盖面积 > 18%
- 君臣佐使比例严重失衡（主色<50%或点缀色>20%）
- 红金绿配色中红和绿都高饱和（饱和度未错峰）

## P1 判定条件

- 主色在五方正色边缘（ΔE 25-30）
- 饱和度 50-60%
- 金色面积 10-18%
- 君臣佐使比例在浮动边缘（主65%/辅25%/点10%）
- 暗调场景底色饱和度 30-40%（偏亮）
- 冷暖光比偏离9:1（7:3 ~ 8:2）

## 与其他规则的关系

- 色彩比例是 03 比例 的视觉表达
- 古金/朱砂 → 04 材料（材料的本色）
- 月白/青灰 → 05 光影（天光和漫反射的颜色）
- 金色节制 → 11 反俗套（亮金大面积=AI国风感HARD FAIL）
- 暗调冷暖光9:1 → 05 光影（光源色温与明暗比）
