# 规则6：色彩体系（Color System）

**规则ID：** color
**优先级：** P0
**模块文件：** modules/color.md

## 目的

使用中国传统色彩体系，体现文化内涵。色彩不是装饰，是"五行"的对应——青(木)、赤(火)、黄(土)、白(金)、黑(水)，每一种颜色都有方位、季节和象征意义。

## 可测指标

| 指标 | 阈值 | 测量方法 |
|---|---|---|
| 主色与五方正色距离 | ΔE ≤ 30 | 计算主色与最近的五方正色的色差 |
| 色彩饱和度 | S ≤ 60%（推荐 ≤ 50%） | HSL 中的 S 值 |
| 主色数量 | ≤ 2种 | 占比 ≥ 10% 的颜色数量 |
| 点缀色占比 | ≤ 10% | 点缀色像素占比 |
| 金色使用 | 哑金/古金，面积 ≤ 15% | 金色像素占比 + 色值检测 |
| 禁忌色 | 无霓虹色/荧光色/紫外光色 | 色值范围检测 |

## 五方正色

| 色名 | 方位 | 五行 | 参考色值 | 说明 |
|---|---|---|---|---|
| 青 | 东 | 木 | #1B5E20 ~ #2E7D32 | 石青/石绿，偏灰偏暗 |
| 赤 | 南 | 火 | #8B2500 ~ #A52A2A | 暗朱砂/赭红，非正红 |
| 黄 | 中 | 土 | #C4A35A ~ #DAA520 | 藤黄/赭黄/琉璃黄，非明黄 |
| 白 | 西 | 金 | #E8E4D9 ~ #F5F5DC | 月白/玉白/象牙白，非纯白 |
| 黑 | 北 | 水 | #1A1A2E ~ #2C2C2C | 玄黑/黛青/墨灰，非纯黑 |

## 已验证配色方案

### 方案一：宋韵清雅（ACT0 推荐）
- 主色：月白 #E8E4D9（天/云，60%）
- 辅色：黛青 #2C3E50（远山/门，25%）
- 点缀：古金 #B8860B（细节，5%）
- 情绪：清雅、高远、宁静

### 方案二：宫墙朱门
- 主色：暗朱砂 #8B2500（墙，50%）
- 辅色：墨灰 #2C2C2C（屋顶，30%）
- 点缀：哑金 #DAA520（门钉/装饰，10%）
- 情绪：庄重、华丽、权力

### 方案三：青绿山水
- 主色：石青 #0D47A1 + 石绿 #1B5E20（山石，50%）
- 辅色：月白 #E8E4D9（水面/天空，40%）
- 点缀：赭黄 #C4A35A（人物，5%）
- 情绪：高远、宁静、传统绘画感

### 方案四：国色单色
- 全屏一种传统色（≥85%）+ 人物/主体用对比色
- 已验证：石绿 #558B2F、藤黄 #F9A825、靛蓝 #1565C0、青翠 #00897B

## 实现建议

1. **从五方正色选主色**，不自行发明颜色。
2. **全部低饱和**：S ≤ 50%，高饱和仅用于 ≤5% 点缀。
3. **金色必须哑**：#B8860B ~ #DAA520，禁止 #FFD700 亮金。
4. **红色必须暗**：#8B2500 ~ #A52A2A，禁止 #FF0000 正红。
5. **阴影有颜色**：阴影用主色的深色版本，不用纯黑。
6. **传统色命名**：用色名（石青/朱砂/月白）指导选色，不用 RGB 数值。

## P0 判定条件

- 主色偏离五方正色范围（ΔE > 30）
- 出现霓虹色/荧光色/紫外光色（如 #00FF00、#FF00FF）
- 使用 #FF0000 正红或 #FFD700 亮金作为主色
- 色彩饱和度 > 60% 且面积 > 20%

## P1 判定条件

- 主色在五方正色边缘（ΔE 25-30）
- 饱和度 50-60%
- 金色面积 10-15%

## 示例参考

- **北京奥运色彩**：中国红、琉璃黄、黛蓝、长城灰、玉白
- **汉服常用色**：青、赤、白、黑、黄五方正色
- **Paul W 红金绿**：暗朱砂底+石绿山水+哑金点缀（1.2万赞）
- **异创视界国色系列**：单色传统色背景+深色人物（1477赞）

## 与其他规则的关系

- 月白/青灰 → 05 光影（天光和漫反射的颜色）
