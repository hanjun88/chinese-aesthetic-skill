# 规则4：材料与质感（Material）

**规则ID：** material
**优先级：** P1
**模块文件：** modules/material.md
**蒸馏来源：** 大唐营造·佛光寺东大殿（斗拱铺作/榫卯抗震/七朱八白彩画）、7位博主（红墙肌理/古松质感/金色节制）

## 目的

遵循古建材料逻辑，偏好天然纹理和色彩。材料不是"贴图"，是"物"——木的纹理、石的粗糙、金的哑光、纸的半透，每一种材料都有真实的物理属性和时间痕迹。核心方法论来自佛光寺东大殿：斗拱同时承担"传力"与"造型"双重职责，榫卯靠柔性变形耗能而非刚性抵抗，七朱八白彩画不是装饰而是结构可读性工具。

## 实现建议

### 1. 斗拱铺作层级与荷载传递 — 传力与造型一体

斗拱垫在柱头与梁架之间，由斗、栱、昂以榫卯层层叠起。干两件事：
- **传力**：屋顶荷载沿"屋顶→斗拱→立柱→地面"路径逐级传下
- **出挑**：靠"昂"这根斜置长木做杠杆，把屋檐远远挑出去（出跳深远），既承重又护墙

**铺作规格**（铺数 = 出跳数 + 3）：
- **柱头铺作**：七铺作双杪双下昂（最高铺数，配两层昂做杠杆出挑）— 要承重+挑檐
- **补间铺作**：五铺作双杪（较低铺数，不出昂）— 两柱之间，主要填层、减小梁枋跨
- **转角铺作**：铺作次序同柱头（七铺作双杪双下昂）— 角部双向出跳、受力复杂

核心：出檐越远、承重越重的位置，铺数越高、昂越多。先定传力路径，再按位置分配铺作规格。

### 2. 榫卯柔性抗震 — 晃而不散、摇而不倒

"柔性耗能、而非刚性抵抗"的抗震设计思维，三层关键：
- **连接留缝**：榫卯节点不是严丝合缝，而是留一定伸缩/滑移余量，可灵活拆装
- **耗能靠变形**：地震来时，框架靠节点间的小幅错动、滑移把地震动能消化掉，而不是用构件硬扛
- **墙不承重**：承力尺度由梁、枋、檩、柱这套"大木作"骨架决定；墙体只负责围护、防风、辅助稳定

结果："晃而不散、摇而不倒""墙倒屋不塌"——墙可开可改可倒，而柱网骨架不失位。

可迁移核心命题：面对冲击性外力，与其把节点做得越刚越好，不如预留可变形、可错动的柔性通道，让系统靠自身微动吸收能量。

### 3. 七朱八白标准化彩画 — 彩画是结构可读性工具

唐代木构彩画的标准化操作程序，核心是在阑额（柱间横向联系梁）上以朱色为底、白色为线：
1. **朱色满刷**：阑额底面满刷朱色（偏紫的朱红，"朱材白壁"中的朱材）
2. **八白均匀分布**：朱底上均匀布置等长的白色横条块，条块间距均等
3. **白条端头入柱**：白色条块的端头与左右柱头相交，视觉上看似直接"插入"立柱中
4. **边缘白线勾边**：所有构件边缘用白线勾勒轮廓，防止单色涂刷把三维穿插的木构糊成一片
5. **构件底部提亮**：栱头、燕尾等构件底部用浅色提亮

底层逻辑：彩画在这里**不是装饰，而是结构可读性工具**。木构是三维穿插体，只刷单一朱色会让构件之间的出头、进退、搭接关系在视觉上糊掉；白色条块和勾边线把结构节点翻译成可读的线条。

东大殿另有"紫燕尾"变体：正面涂绛紫，侧棱以白色画出凹形。

### 4. 博主验证的材质方法论

**红墙肌理（设计师陈欢）**：
- 基色朱砂 #C8102E/#C0392B（非鲜艳正红），暗部偏 #8B0000，亮部偏 #D4544A
- 底层夯土/抹灰哑光粗糙度 80-90%
- 中层墙面不均匀色差，局部褪色偏 #A03020 或泛灰
- 表层砖缝/拼接痕迹若隐若现，裂缝 0.5-2px
- 同面墙呈现 2-3 个色阶

**古松质感（设计师陈欢/书香Design）**：
- 松干主色墨绿偏褐 #2D5A27，暗部 #1A3015，亮部 #4A7A3A
- 树皮纵向深裂 1-3px，裂纹色近黑绿 #0F1F0A
- 主干至少一次 90° 以上弯曲，分枝呈"鹿角状"
- 逆光时松针边缘出现 1-2px 暖金/米白轮廓光 #E8D080

**金色节制（6位博主共识）**：
- 金色画面覆盖面积硬上限 18%
- 大幅金只用于龙脉主峰轮廓、宫观主体、瀑布/河流自发光带、峰顶尖光
- 金色必须分层：近景金线厚重清晰、远景淡金虚化、阴处碎金隐现
- 金色必须配深色底（群青/深紫/墨黑），靠冷暖明度对比让金"发光"

## P1 判定条件

- 使用明显非中式材质（光滑塑料、过度饱和金属、现代玻璃）
- 材质映射与场景风格不符（云海场景用金属地板）
- 材质过于全新（无风化/磨损/苔藓痕迹）
- roughness < 0.3 且 metalness < 0.1（塑料感）
- 斗拱铺作不匹配位置（补间用了比柱头更高的铺作）
- 七朱八白彩画白条端头不入柱（浮在阑额表面）
- 金色覆盖面积 > 18%，或金色配浅色底（金不发光）
- 墙体参与承重（违背大木作骨架原则）

## 示例参考

- **佛光寺东大殿**：木构建筑，斗拱七铺作双杪双下昂（柱头），榫卯柔性连接，七朱八白彩画，木材有千年风化痕迹，斗拱裸露无后世彩画覆盖
- **徽派民居**：白粉墙（土/石灰）+ 黑瓦（陶土），材质对比强烈
- **设计师陈欢红墙古松**：夯土哑光红墙+硬光投影+墨绿苍劲古松+逆光金边
- **Paul W 鎏金瀑布**：暗底+金色纹理，金色是哑金非亮金，覆盖≤18%
- **反例**：光滑塑料感的"中式门"= FAIL；亮金 #FFD700 大面积覆盖 = FAIL

## 与其他规则的关系

- 材料的本色是 06 色彩 的来源
- 材料的粗糙度影响 05 光影 的反射/漫反射
- 斗拱出挑深度直接影响 03 比例 的出檐/柱高比
- 金粉/云雾是 07 动势 的载体
- 时间痕迹（风化/包浆/苔藓）是 08 时间感 的视觉表达
- 七朱八白的朱底白条是 06 色彩 唐代官式涂装的标准化参考

## IVAN CHIU 云海天宫系列新增原则（11图实证）

> 来源：抖音博主 IVAN CHIU（@_IVANCHIU）Midjourney Prompt Test 系列 11 张图文。全部附带完整提示词。

### 新增原则 M1：金白玉质对撞（Gold-Jade-Material-Contrast）——鎏金与白玉的核心材质二元

- **触发场景**：所有天宫/宫殿/玉岛/超现实中式建筑
- **可执行操作**：
  1. 屋顶/斗拱/装饰用"液态金"（liquid gold），建筑主体/栏杆/台阶用"白玉"（white jade）；
  2. 金在高处（屋顶/飞檐/斗拱），玉在低处（墙体/栏杆/台阶），形成"金顶玉身"经典格局；
  3. 朱红漆（vermilion lacquer）作为第三色点缀，仅用于柱子，占比 ≤ 10%；
  4. 金的不透明金属感 vs 玉的半透明通透感，形成材质对比（配合 L2 玉质内发光）。
- **硬参数**：金质面积 ≤ 30%（屋顶+装饰）；玉质面积 ≥ 40%（主体）；朱红点缀 ≤ 10%；金必须是 `liquid gold` 而非普通黄色。
- **反例**：全金建筑 = 俗气暴发户；全玉无金 = 单调缺乏重点；朱红大面积 = 喧宾夺主。
- **与已有规则关系**：扩展原有"金"材料（从"哑金点缀≤18%"升级为"金顶玉身整体格局"）；与 `cool-field-warm-point`（color）配合（冷玉=场，暖金=点）。

### 新增原则 M2：整玉雕刻巨构（Single-Piece-Jade-Colossus）——由整块白玉雕刻而成的不可能巨构

- **触发场景**：天门/玉柱/玉桥/需要"工艺极致感"的超现实建筑
- **可执行操作**：
  1. 明确标注"由整块白玉雕刻而成"（carved from a single piece of pristine white jade）；
  2. 巨构尺度——天门高到"群山如卵石"，玉柱穿透三层云海；
  3. 表面有精细浮雕——云纹/凤凰纹/兽首（spiral relief carvings of cloud and phoenix patterns）；
  4. 玉质半透明，内部发光（配合 L2），边缘有光晕。
- **硬参数**：必须标注 `carved from a single piece`；必须有浮雕装饰（云纹/凤凰纹/兽首至少一种）；尺度必须是"巨构"（高到反衬群山/穿多层云海）。
- **反例**：由多块玉拼接 = 失去"整玉"工艺极致感；无浮雕 = 光滑白柱，缺乏细节；正常尺度 = 失去"不可能巨构"的超现实感。
- **与已有规则关系**：新增——是原有"石"材料的超现实极端形态（从"粗糙哑光石"升级为"整玉雕刻巨构"）；与 `monumental-scale`（spatial）配合（整玉巨构的尺度强化）。

### 新增原则 M3：云纹兽首装饰（Cloud-Pattern-Beast-Head-Ornament）——建筑表面的中式纹样系统

- **触发场景**：所有需要"中式建筑识别度"的场景（栏杆/基座/柱础/屋檐）
- **可执行操作**：
  1. 栏杆雕刻云纹（carved cloud patterns on railings），望柱用兽首（beast-head balustrade posts）；
  2. 建筑基座用守护石狮（guardian lion statue / guardian lion base）；
  3. 玉柱/玉桥表面有螺旋浮雕云纹和凤凰纹（spiral relief carvings of cloud and phoenix patterns）；
  4. 斗拱/飞檐保持传统中式形制（gold dougong brackets, flying eaves）。
- **硬参数**：至少2种中式纹样（云纹/兽首/石狮/斗拱/飞檐）；栏杆必须有云纹或兽首（二选一）；基座必须有石狮或兽首（二选一）。
- **反例**：光滑无装饰的白玉栏杆 = 现代极简，失去中式识别度；用欧式柱头/线脚 = 风格混乱；纹样过于繁复 = 装饰过载。
- **与已有规则关系**：扩展原有"斗拱"材料原则（从"传力+造型"扩展到"整体纹样系统"）；与 `dougong-flying-eaves`（建筑语汇）配合。

## 风铃Muse 中式巨构教程系列新增原则（视频蒸馏）

> 来源：抖音博主 风铃Muse《30s学会做中式巨构东方仙境保姆级教程》，1分52秒视频，6个AI生成场景分析。

### 新增原则 M4：荷花水面仙境基底（Lotus-Water-Immortal-Base）——荷花覆盖水面作为仙境识别符号

- **触发场景**：所有需要"东方仙境感"的水景场景（天宫莲池/仙界荷塘/云海水面）
- **可执行操作**：
  1. 水面必须覆盖 ≥ 40% 的荷花/荷叶——荷花不是装饰，是"仙境基底"；
  2. 荷花颜色：粉色/白色（传统色），不能用红色/黄色等非传统色；
  3. 荷叶大小错落——大荷叶（直径 > 人高）+ 小荷叶 + 荷花苞，至少3种尺寸；
  4. 水面必须有倒影——建筑/天空/人物倒映在水中；
  5. 荷花可以"超尺度"——比正常大3-5倍，增加超现实感。
- **硬参数**：
  - 荷花/荷叶覆盖水面 ≥ 40%
  - 荷花颜色：粉色/白色（传统色）
  - 必须有水面倒影
  - 荷叶大小错落（至少3种尺寸）
- **反例**：水面无荷花 = 普通水景（无仙境感）；荷花颜色用红/黄 = 失去东方传统感；荷叶大小一致 = 缺乏自然层次。
- **与已有规则关系**：新增——是东方仙境特有的植物基底；与 `monumental-micro-figure-immortal`（S12）配合（荷花是仙境配方的环境元素变体）。
