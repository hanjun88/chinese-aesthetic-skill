# ACT0 云海+单门 — Master Plate 主模板规范

## 场景概述

满屏云海中央一扇中式木门，天空蓝白相间，云海氤氲。门顶施歇山顶，出檐深远；门身为红木色带青檐，白玉石地面。前景云雾流动，视野开阔。

**核心意象：** "满屏云海中一扇门"——中轴对称、留白突出、界的隐喻。

## 构图规范

| 参数 | 值 | 说明 |
|---|---|---|
| 画幅 | 16:9（1920×1080）/ 9:16（1080×1920） | 双画幅适配 |
| 门位置 | 屏幕中心，X轴偏移 ≤ 5% | 中轴对称 |
| 门占画面高度 | 30-40% | 巨构感但不压迫 |
| 天空/云海占比 | 60-70% | 留白为主 |
| 地面占比 | 10-15% | 青石板地面 |
| 人物 | 可选，占画面 ≤ 3%，门前/门侧，背影 | 尺度锚点 |
| 不完整入画 | 门的一侧或屋顶顶部被画面边缘裁切 | 暗示更大存在 |

**深度分层：**
- Layer 0（最远）：天空/远景云海，depth=1.0
- Layer 1：中景云海，depth=0.7
- Layer 2：门体，depth=0.3
- Layer 3（最近）：前景云雾/金粉，depth=0.1

## 色彩方案（宋韵清雅）

| 元素 | 色值 | 占比 | 说明 |
|---|---|---|---|
| 天空 | #87CEEB ~ #B0E0E6 | 30% | 蔚蓝，渐变到月白 |
| 云海 | #E8E4D9 ~ #F5F5DC | 35% | 月白/乳白，半透明 |
| 门（木） | #8B4513 ~ #5D4037 | 15% | 檀木红/乌木，半光 |
| 屋檐 | #C28840 ~ #8B7355 | 5% | 暗黄红/赭石 |
| 地面（石） | #A9A9A9 ~ #696969 | 10% | 青石板，粗糙 |
| 基座 | #4B4B4B ~ #2C2C2C | 3% | 深灰青石 |
| 金粉（点缀） | #DAA520 ~ #B8860B | ≤2% | 哑金，随滚动出现 |

## 三大结构选择

1. **中轴为骨但不严格对称**：门在中心，云海流动打破绝对对称，人物在一侧（黄金分割点）
2. **大虚小实 7:3**：云海/天空 70%，门/地面/人 30%
3. **不完整入画**：门的屋顶顶部或一侧被画面边缘裁切

## 与引擎规则的映射

| 规则 | ACT0 应用 |
|---|---|
| 空间秩序 | 门沿中轴，云海分层，前庭留白 |
| 虚实关系 | 云海60-70%留白，门体剪影，不完整入画 |
| 比例 | 门高宽比 1:2（佛光寺比例），三段式（台基:屋身:屋顶=1:2:1） |
| 材料 | 乌木门+青石板地+哑金点缀，roughness≥0.5 |
| 光影 | 侧光（早晨斜射）+ 体积光（从云缝漏下），软阴影 |
| 色彩 | 宋韵清雅方案，月白+黛青+古金，全部低饱和 |
| 动势 | 云海缓慢流动（4-8秒周期），金粉随滚动螺旋 |
| 时间感 | 木梁风化，石面苔藓，云流光影变化 |
| 禁忌 | 无正红/亮金，无传统纹样满铺，无建筑细节堆砌 |
| 交互 | 鼠标扰动云海→点击生长苔藓→拖拽门旋转→滚动下潜 |
